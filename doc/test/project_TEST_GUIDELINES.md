# CareMemo テスト実施ガイドライン

本プロジェクトにおけるテストの分類と、それぞれの目的・役割を定義します。開発が進むにつれ、これらのテストを段階的に構築することで、品質の維持（デグレ防止）を図ります。

---

## 1. ロジック・データ層のテスト (Unit Test)
**「目に見えないところ」の検証（現在、精度を向上させている領域）**

- **対象:** 純粋なロジック、計算、データ変換、リポジトリ、ViewModel の内部状態。
- **場所:** `app/src/test/` (Local Unit Test)
- **目的:** 入力データに対して、期待される正しい出力（または状態）が返るかを検証する。

## 2. UI 層のコンポーネント・挙動テスト (Component / UI Test)
**「画面の見た目」と「タップ時の反応」の検証（現在、画面IDに基づいて整理・固めている領域）**

このカテゴリは、さらに以下の 2 つのレベルに分けて実施します。

### 2-A. コンポーネント単体テスト (MainScreenContent 等)
- **対象:** 画面のレイアウト、部品の表示・非表示、引数による見た目の変化。
- **メリット:** ViewModel を介さずデータを直接注入するため、特定のパターンを高速に網羅できる。

### 2-B. 画面全体の挙動結合テスト (MainScreen 本体等)
- **対象:** 画面（View）と「脳（ViewModel）」の連動。
- **検証内容:** 
    - ボタン操作によってスナックバーやダイアログが表示されるか。
    - ViewModel から発行されたイベントによって画面状態が正しく更新されるか。
- **画面遷移の責任分界ルール:**
    仕様書とテストコードの肥大化を防ぐため、画面遷移の検証責任を以下のように分離する。
    - **呼び出し元（親）の責任:** 他の画面（子）への遷移を開始する操作と、正しく子画面へ遷移したかの検証を担当。
        - 例: `SCR-M-001` (親) のテストで、利用者タップにより `SCR-PH-001` (子) へ遷移することを検証。
    - **呼び出し先（子）の責任:** その画面自体の表示、内部の操作、および「戻る」操作による画面の終了を担当。
        - 例: `SCR-PH-001` のテストで、戻るボタン押下により画面が終了（PopBackStack）することを検証。

## 3. 導線・遷移のテスト (Integration / E2E Test)
**「画面をまたいだデータの整合性」の検証（今後、段階的に着手する領域）**

- **対象:** 画面間の移動を伴う、複数の画面をまたいだデータの整合性。
- **検証内容:** 
    - 子画面（詳細画面など）で入力・保存した内容が、親画面（一覧画面など）に戻ったときに正しく反映されているか（バッジの更新、リストの再読み込みなど）。
    - 設定画面で変更した内容（氏名伏せ字設定など）が、アプリ全体（全画面）で正しく適用されているか。
- **目的:** ユーザーの業務ストーリーが途切れることなく、かつデータが正しく受け渡されているかを保証する。

---

## テスト作成の基本ルール
- **デグレ防止のガードレール:** 主要なボタンや表示項目には `testTag` を付与し、UI 変更時に意図せず機能が消えることを防ぐ。
- **仕様の明文化:** `doc/test/screen/` 配下の仕様書と 1:1 で対応させ、テストコード自体が「この画面はどう動くべきか」という生きた仕様書として機能するように記述する。

---

## 付録：画面遷移の親子関係（テスト分担の基準）
遷移の「行き」のテストをどの仕様書に記述するかの基準です。

| 親（遷移開始の検証担当） | 子（画面内の検証担当） | 備考 |
|:---|:---|:---|
| **SCR-M-001** (一覧) | **SCR-PH-001** (健康) | 詳細画面への基本遷移 |
| | **SCR-PH-002** (一括入力) | FABまたはメニューからの遷移 |
| | **SCR-M-002** (利用者編集) | 編集ボタンからの遷移 |
| **SCR-PH-001** (健康) | **SCR-PH-003** (グラフ拡大) | グラフエリアタップ |
| **SCR-PC-001** (所見) | **SCR-PC-002** (プレビュー) | カメラ撮影・写真タップ（編集） |
| | **SCR-PC-003** (全画面) | 写真タップ（閲覧） |
| **SCR-S-001** (設定) | **SCR-S-002** (操作ログ) | 設定項目からの遷移 |
