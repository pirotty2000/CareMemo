# テスト仕様書 - UserSettingsRepository

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/data/repository/UserSettingsRepositoryTest.kt`

## 1. 概要
ユーザー設定（DataStore）の永続化、初期値管理、設定変更のリアクティブな通知、およびメモリ保持フラグの正確性を検証する。
実機（またはエミュレータ）のコンテキストを必要とするため、Instrumented Test として実施する。

## 2. 永続化・通知テスト (Persistence & Flow)
**目的:** 各種設定値が正しく保存され、Flow を通じて即座に通知されることを検証する。

| ID     | テスト項目    | 検証内容                           | 期待結果                          |
|:-------|:---------|:-------------------------------|:------------------------------|
| SET-01 | 氏名伏せ字設定  | `setNameMaskingEnabled` の実行と購読 | 保存した真偽値が Flow から取得できること       |
| SET-02 | テーマ設定    | `setThemeSetting` の実行と購読       | Enum 値が文字列として永続化され、正しく復元されること |
| SET-03 | 記録者名設定   | `setDefaultRecorderName` の実行   | 任意の文字列が保存・取得できること             |
| SET-04 | ログ保持期間   | `setAuditLogRetentionDays` の実行 | 数値（日）が保存・取得できること              |
| SET-05 | タイムアウト設定 | `setLockTimeoutMinutes` の実行    | 数値（分）が保存・取得できること              |

## 3. 初期値テスト (Defaults)
**目的:** 未設定（初回起動時）の状態で、設計通りのデフォルト値が返されることを検証する。
※ テスト環境の制約上、クリーンな状態での検証を優先する。

| ID     | テスト項目      | 検証内容              | 期待結果                                 |
|:-------|:-----------|:------------------|:-------------------------------------|
| DEF-01 | デフォルト値の整合性 | 設定未投入状態での各プロパティ取得 | 氏名伏せ字:true, ログ保持:30, タイムアウト:0 等であること |

## 4. 特殊状態テスト (Memory / Security)
**目的:** メモリ上のみで保持される状態や、セキュリティ関連の特殊なロジックを検証する。

| ID     | テスト項目     | 検証内容                        | 期待結果                                |
|:-------|:----------|:----------------------------|:------------------------------------|
| SPC-01 | ロックバイパス   | `isLockBypassed` への代入       | メモリ上で正しく保持され、永続化はされないこと             |
| SEC-01 | 不正テーマ値の復済 | DataStore に不正な文字列が保存されている状態 | `ThemeSetting.SYSTEM` にフォールバックされること |
