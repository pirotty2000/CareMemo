# テスト仕様書 - PersonSummaryRepository

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/data/repository/PersonSummaryRepositoryTest.kt`

## 1. 概要
利用者の各記録カテゴリ（健康、所見、服薬）におけるデータ有無の集計（サマリー）取得ロジックを検証する。
特に、複数 DAO の Flow 統合（リアルタイム更新）と、全利用者一括取得時のデータマッピングを対象とする。

## 2. 個別サマリー取得テスト (getPersonCategorySummaryById)
**目的:** 特定の利用者の 5 つのデータ系統が正しく統合され、いずれかの変更がリアルタイムに反映されることを検証する。

| ID     | テスト項目   | 検証内容                         | 期待結果                                       |
|:-------|:--------|:-----------------------------|:-------------------------------------------|
| IND-01 | Flow 統合 | 各カテゴリ DAO から異なる真偽値の Flow を返却 | `PersonCategorySummary` の各プロパティに正しく反映されること |

## 3. 全利用者サマリー取得テスト (getPersonCategorySummaries)
**目的:** 全利用者一括取得のクエリ結果が、利用者 ID をキーとする正しいマップ形式に変換されることを検証する。

| ID     | テスト項目 | 検証内容                                 | 期待結果                            |
|:-------|:------|:-------------------------------------|:--------------------------------|
| ALL-01 | マップ変換 | 複数名分の `PersonSummaryQueryResult` を返却 | ID をキー、サマリーを値とする正しい Map が得られること |
