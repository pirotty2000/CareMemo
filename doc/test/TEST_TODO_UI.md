## 3. 今後の展望 (Phase 3: Integration / E2E)
UI 単体・挙動テストが全て完了した後、複数の画面をまたぐシナリオテストを実施します。

- **シナリオ例 A**: 新規利用者登録 → 健康記録入力 → 一覧画面で最新記録バッジを確認。
- **シナリオ例 B**: 服薬記録を入力 → PDF設定ダイアログ起動 → PDF出力（モック）のトリガー確認。
- **シナリオ例 C**: 設定でマスキングを有効化 → 全ての画面で氏名が伏せ字になっていることを確認。

### 3-B. 体験重視の回帰テスト (実体験に基づく重点項目)
過去のデグレード（先祖返り）や、多段遷移による状態管理が「怪しい」箇所の導線チェック。

- **カメラ撮影導線**: 所見メモでの写真撮影後、自動的にプレビュー（フル画面表示）へ正しく遷移することの確認。
- **多段遷移の状態維持**: メイン → 詳細 → 入力ダイアログ → 保存、といった多段遷移後に、前の画面に戻った際の状態（スクロール位置やバッジの即時反映）の確認。
- **外部連携後の復帰**: PDF出力（別アプリ起動）やバックアップ保存から戻った際、アプリがロック画面または元の状態で正常に再開できるかの確認。
