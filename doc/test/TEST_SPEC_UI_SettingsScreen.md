# UI層テスト仕様書 - Settings (設定・管理)

## 1. コンポーネント単体テスト (SettingsScreenContent)
**目的:** 設定項目の表示、初期値の反映、スイッチの切り替えによるUIの変化などを検証する。

| ID | テスト項目 | 検証内容 |
|:---|:---|:---|
| CP-01 | 初期値の表示反映 | 各設定項目（マスキング、記録者名、認証、待機時間、テーマなど）が引数で渡された初期値を正しく表示していること。 |
| CP-02 | マスキングのトグル | 「氏名の伏せ字表示」スイッチの切り替えで、`onMaskingChange` コールバックが呼ばれること。 |
| CP-03 | 記録者名の入力 | デフォルト記録者名に入力した際、`onRecorderNameChange` が呼ばれること。 |
| CP-04 | バックアップパスワードの表示制御 | パスワード保護設定をOFFにするとパスワード入力欄が非表示になり、ONにすると表示されること。 |
| CP-05 | パスワードのバリデーション | パスワードが6文字未満の場合、エラーメッセージが表示され、エクスポートボタンが非活性になること。 |
| CP-06 | パスワードの可視性切り替え | 目のアイコンをタップして、パスワードの伏せ字・表示が切り替わること。 |
| CP-07 | セキュリティ待機時間の表示 | 選択されている待機時間（即時、5分など）が正しくラベル表示されていること。 |
| CP-08 | ローディング/処理中表示 | `isProcessing = true` の時、進捗ダイアログが表示され、背後の操作がロックされること。 |

## 2. 画面全体の挙動・結合テスト (SettingsScreen)
**目的:** ダイアログの開閉、開発者モードの隠しコマンド、およびセキュリティ解除時の認証要求を検証する。

| ID | テスト項目 | 検証内容 |
|:---|:---|:---|
| BH-01 | 待機時間設定ダイアログ | 「再ロックまでの時間」タップで選択ダイアログが開き、項目選択で値が更新されること。 |
| BH-02 | テーマ設定ダイアログ | 「配色とモード」タップで選択ダイアログが開き、項目選択でテーマが反映されること。 |
| BH-03 | 開発者モードの有効化 | バージョン情報を7回連続タップすることで、管理者向け設定セクションが表示されること。 |
| BH-04a | パスワード保護解除時の認証 | 「バックアップにパスワードを設定」スイッチをONからOFFにする際、`onRequireAuthentication` が呼ばれること。 |
| BH-04b | パスワード表示時の認証 | パスワードの目玉アイコンをタップして「表示」状態（平文表示）にする際、`onRequireAuthentication` が呼ばれること。 |
| BH-04c | アプリロック解除時の認証 | 「アプリのロック」スイッチをONからOFFにする際、`onRequireAuthentication` が呼ばれること。 |
| BH-05 | 利用者管理の遷移 | 「利用終了者の復帰」をタップした際、復帰画面への遷移コールバックが呼ばれること。 |
| BH-06 | 操作ログ保持期間の設定 | 管理者ツール内のログ保持期間をタップし、ダイアログから変更できること。 |
| BH-07 | 全データ消去のガード | 管理者ツールの「全データ消去」タップ時に、即座に実行されず、まず認証が求められ、その後に確認ダイアログが表示されること。 |

## 3. テスト用タグ (testTag) 定義
- `Settings_MaskingSwitch`: 氏名伏せ字スイッチ
- `Settings_RecorderName`: 記録者名入力
- `Settings_BackupPasswordSwitch`: バックアップパスワードスイッチ
- `Settings_BackupPasswordInput`: パスワード入力フィールド
- `Settings_PasswordVisibilityToggle`: パスワード表示/非表示ボタン
- `Settings_ExportButton`: エクスポートボタン
- `Settings_ImportButton`: インポートボタン
- `Settings_BiometricSwitch`: アプリロックスイッチ
- `Settings_TimeoutRow`: 再ロック待機時間行
- `Settings_ThemeRow`: テーマ設定行
- `Settings_VersionRow`: バージョン情報行
- `Settings_ProcessingDialog`: 処理中ダイアログ
- `Settings_DevSection`: 管理者向けセクション
- `Settings_ClearAllButton`: 全データ消去ボタン
- `Settings_AuditLogViewButton`: 操作ログ参照ボタン
- `Settings_IntegrityCheckButton`: 整合性チェックボタン

## 4. 実装状況と未実施項目の理由
今回のUIテスト実装（`SettingsScreenTest.kt`）において、一部の項目は以下の理由により実装を省略、または類似項目の検証をもって代替とした。

| ID | テスト項目 | 未実施・代替の理由 |
|:---|:---|:---|
| CP-03 | 記録者名の入力 | `CP-02` (マスキングのトグル) にて、Composeの状態変更がViewModelへ伝達される基本構造を検証済みであるため。同一パターンであるテキスト入力の検証は省略した。 |
| BH-05 | 利用者管理の遷移 | 単純なナビゲーションコールバックの実行であり、`BH-01` 等で行った「行タップによるイベント発火」の検証パターンに含まれるため。 |
| BH-06 | 操作ログ保持期間の設定 | `BH-01` (待機時間) および `BH-02` (テーマ) と全く同一の `AppDialog` 選択パターンを使用しており、これらでダイアログの開閉挙動が確認できているため。 |
| BH-07 | 全データ消去のガード | 本項目は「認証要求 (`BH-04`)」と「確認ダイアログ表示 (`BH-01`)」の複合的な挙動である。それぞれの要素技術を個別に検証済みであるため、統合的な検証は省略した。 |
| CP-06 | パスワード可視性切り替え | `BH-04b` にて、アイコンタップ時に「認証要求が飛ぶこと」を検証している。認証成功後の表示切り替えは Compose の標準的な状態遷移であるため、省略した。 |
| CP-07 | 待機時間の表示反映 | `CP-01` (初期値表示) および `BH-01` (ダイアログ開閉) の検証に含まれるため。 |
