# UI層テスト仕様書 - GraphExpansion (グラフ拡大表示)

- **対象テストコード:**
    - `androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/health/GraphExpansionScreenTest.kt`

## 1. 画面表示テスト (GraphExpansionScreen)
**目的:** 横画面に固定された状態で、グラフが大きく、正しく表示されていることを検証する。

| ID | テスト項目 | 検証内容 |
|:---|:---|:---|
| CP-01 | 基本レイアウト表示 | ヘッダーに戻るボタン、利用者名、およびカテゴリ名が表示されていること。 |
| CP-02 | グラフリストの表示 | 指定されたカテゴリに応じた数のグラフ（Card）が縦に並んで表示されていること。 |
| CP-03 | 初期グラフのハイライト | 遷移時に指定されたインデックスのグラフが強調表示（枠線の点滅等）されること。 |
| CP-04 | ローディング表示 | データのロード中にローディングインジケーターが表示されること。 |
| CP-05 | 空状態の表示 | 記録データが0件の場合、「記録がありません」と表示されること。 |

## 2. 画面全体の挙動・結合テスト (GraphExpansionScreen)
**目的:** 画面回転の制御や戻る操作が期待通りに動作することを検証する。

| ID | テスト項目 | 検証内容 |
|:---|:---|:---|
| BH-01 | 画面回転の強制 | 画面表示時に自動的に横画面（LANDSCAPE）に切り替わり、終了時に元の向きに戻ること。 |
| BH-02 | スクロール連動 | グラフが複数ある場合、縦スワイプで各グラフを閲覧できること。 |
| BH-03 | 戻る操作 | 戻るボタンをタップした際、`onBack` コールバックが呼ばれること。 |

## 3. テスト用タグ (testTag) 定義
- `GraphExpansion_BackButton`: 戻るボタン
- `GraphExpansion_HeaderTitle`: ヘッダーのタイトル（氏名・カテゴリ）
- `GraphExpansion_GraphList`: グラフのスクロールコンテナ（LazyColumn）
- `GraphExpansion_GraphCard_{index}`: 各グラフのカード項目
- `GraphExpansion_Loading`: ローディング表示
- `GraphExpansion_EmptyState`: 空状態表示
