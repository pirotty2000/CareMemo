# テスト仕様書 - SCR-M-001 MainScreen

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/main/MainScreenTest.kt`
    - `app/src/test/java/jp/mydns/fujiwara/carememo/viewmodel/PersonListViewModelTest.kt`

## 1. コンポーネント単体テスト (MainScreenContent)
**目的:** 利用者リストの表示、検索、フィルタリング、空状態などの表示ロジックを検証する。

| ID    | テスト項目    | 検証内容                                         |
|:------|:---------|:---------------------------------------------|
| CP-01 | 空状態の表示   | 利用者が0件の時、空状態のメッセージが表示されること。                  |
| CP-02 | ローディング表示 | `isLoading = true` の時、LoadingScreenが表示されること。 |
| CP-03 | 利用者リスト表示 | 利用者が存在する場合、リスト形式で正しく表示されること。                 |
| CP-04 | 名前マスキング  | 設定が有効な時、氏名が「山○ 太○」のように伏せ字で表示されること。           |
| CP-05 | 記録バッジの表示 | 各カテゴリ（血圧・所見・服薬）に記録がある場合、対応するバッジが表示されること。     |
| CP-06 | 検索結果なし表示 | 検索ワードに一致する利用者がいない時、専用のメッセージが表示されること。         |
| CP-07 | 長大な氏名の表示 | 非常に長い氏名を持つ利用者の場合、レイアウトが崩れず適切に表示（または省略）されること。 |

## 2. 画面全体の挙動・結合テスト (MainScreen)
**目的:** ユーザーの操作（検索、メニュー、ナビゲーション）が正しく機能することを検証する。

| ID    | テスト項目      | 検証内容                                                                                                              |
|:------|:-----------|:------------------------------------------------------------------------------------------------------------------|
| BH-01 | ハンバーガーメニュー | メニューボタン押下でドロワーが開き、**SCR-S-001** (設定) やバージョン情報へ正しく遷移できること。                                                         |
| BH-02 | 検索機能       | 検索窓へのテキスト入力で、`onSearchQueryChange` が呼ばれること。                                                                       |
| BH-03 | カナ索引の選択    | カナ索引（あ・か・さ...）のタップで、`onSectionSelect` が呼ばれること。                                                                    |
| BH-04 | 利用者メニュー    | 各項目の編集ボタン押下で、**対象の利用者IDを保持して** SCR-M-002 (編集モード) へ正しく遷移すること。                                                      |
| BH-05 | 利用終了とUndo  | 利用終了時、スナックバーが表示され「元に戻す」で操作がキャンセル（DBへの反映を阻止/復元）できること。                                                              |
| BH-06 | 新規追加ボタン    | 右下の「＋」ボタン押下で、新規モードとして **SCR-M-002** へ正しく遷移すること。                                                                   |
| BH-07 | 詳細画面への遷移   | 利用者項目（または記録バッジ）をタップした際、**選択した利用者IDを保持して** SCR-PH-001 (健康)、SCR-PC-001 (所見)、SCR-PM-001 (服薬) の各詳細画面へ正しく遷移すること。       |
| BH-08 | エラーダイアログ表示 | ViewModel からエラーイベントが発行された際、共通エラーダイアログが表示されること。                                                                    |
| BH-09 | 状態の維持      | 検索クエリ入力後に詳細画面へ遷移し、戻った際に検索クエリとリストのスクロール位置が維持されていること。                                                               |
| BH-10 | 一括入力への遷移   | FAB（またはメニュー）から **SCR-PH-002** (一括入力) へ正しく遷移すること。                                                                  |
| BH-11 | 戻り時のリスト更新  | 詳細画面（**SCR-PH/PC/PM**）、編集画面（**SCR-M-002**）、設定画面（**SCR-S-001**）から戻った際、**変更内容（氏名伏せ字や記録バッジ等）がリスト上の表示に即座に反映されていること。** |

## 3. ロジック・安全性テスト (PersonListViewModel)
**目的:** 例外発生時もローディング状態が適切に解除され、監査ログにエラーが記録されることを検証する。

| ID    | テスト項目        | 検証内容                                                                                                 |
|:------|:-------------|:-----------------------------------------------------------------------------------------------------|
| LG-01 | データ取得失敗時の安全性 | 利用者一覧の取得（Flow）中に例外が発生した際、`uiState.isLoading` が `false` になり、エラーダイアログが表示され、監査ログに "ERROR" が記録されること。     |
| LG-02 | 保存/削除失敗時の安全性 | 利用者の登録、利用終了、復帰処理中に例外が発生した際、`uiState.isLoading` が `false` になり、エラーダイアログが表示され、監査ログに "ERROR" が記録されること。   |
| LG-03 | 状態の原子性       | 検索クエリを更新した際、`uiState.searchQuery` と `uiState.selectedSection` (「全」へのリセット) が単一の `update` で同時に反映されること。 |
| LG-04 | 設定の同期        | `UserSettingsRepository` のマスキング設定が変更された際、`uiState.isNameMaskingEnabled` に即座に反映されること。                 |

## 4. テスト用タグ (testTag) 定義
- `MainScreen_EmptyState`: 空状態表示
- `MainScreen_Loading`: ローディング画面
- `MainScreen_UserList`: 利用者リスト
- `UserListItem_{id}`: 各利用者の項目
- `MainScreen_SearchBox`: 検索窓
- `MainScreen_MenuButton`: ハンバーガーメニューボタン
- `MainScreen_AddButton`: 新規登録ボタン
- `UserListItem_MenuButton`: 各項目の操作メニューボタン
