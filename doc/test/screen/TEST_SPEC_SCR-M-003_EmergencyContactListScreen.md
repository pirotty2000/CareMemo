# テスト仕様書 - SCR-M-003 EmergencyContactListScreen

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/main/EmergencyContactListScreenTest.kt`

## 1. 概要
緊急連絡先一覧画面（EmergencyContactListScreen）における表示（Rendering）および、ユーザー操作に伴う意図（Intent）伝達、ナビゲーションの実行を検証する。
データの加工（電話番号整形等）や保存・削除のロジックは ViewModel/Logic 側のテストで保証されているため、本テストでは UI 部品の描画とイベント発行に特化する。

## 2. 表示テスト (Display)
**目的:** `EmergencyContactUiState` に基づき、連絡先リストや利用者名が正しく描画されることを検証する。

| ID     | テスト項目     | 条件 (UiState)          | 期待結果                                                  |
|:-------|:----------|:----------------------|:------------------------------------------------------|
| DSP-01 | タイトルの利用者名 | `personName = "利用者名"` | ヘッダーに「利用者名 様の緊急連絡先」等の形式で表示されること                       |
| DSP-02 | 連絡先リスト描画  | `contacts` にデータあり     | 施設名、担当者名、整形された電話番号が各項目に表示されること                        |
| DSP-03 | 空状態の表示    | `contacts` が空         | 「連絡先が登録されていません」等のメッセージが表示されること                        |
| DSP-04 | ローディング表示  | `isLoading = true`    | プログレスバー等が表示され、読み込み中であることが視覚的にわかること（※Scaffold内の実装に準ずる） |

## 3. 操作・インタラクションテスト (Interaction)
**目的:** ユーザーのタップ操作が、ViewModel の適切なアクションまたは削除確認ダイアログの表示に繋がることを検証する。

| ID     | テスト項目    | 操作                | 期待結果 (UI の挙動)                                |
|:-------|:---------|:------------------|:---------------------------------------------|
| ACT-01 | 新規追加ボタン  | FAB (+) をタップ      | `onAddClick` コールバック（または ViewModel 遷移）が呼ばれること |
| ACT-02 | 編集メニュー選択 | 項目内の編集アイコン ➔ 「編集」 | `onEditClick` が該当する連絡先データとともに呼ばれること          |
| ACT-03 | 削除確認表示   | 項目内の編集アイコン ➔ 「削除」 | 削除確認ダイアログが表示されること                            |
| ACT-04 | 削除実行確定   | 削除ダイアログで「削除」を選択   | `onDeleteConfirm` が呼ばれ、ダイアログが閉じること           |

## 4. ナビゲーション実行テスト (Navigation)
**目的:** 戻る操作等が実際に画面遷移として実行されることを検証する。

| ID     | テスト項目 | 操作               | 期待結果                                         |
|:-------|:------|:-----------------|:---------------------------------------------|
| NAV-01 | 戻る操作  | TopAppBar の戻るボタン | `navController.popBackStack()` 相当の処理が実行されること |

## 5. テスト用タグ (testTag)
- `MedicalContactList_AddButton`: 新規登録 FAB
- `MedicalContactList`: 連絡先一覧コンテナ
- `EmergencyContactItem_{id}`: 各連絡先項目（※実装に応じて調整）
