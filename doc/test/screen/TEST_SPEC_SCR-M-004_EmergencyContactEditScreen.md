# テスト仕様書 - SCR-M-004 EmergencyContactEditScreen

- **対象テストコード:** `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/main/EmergencyContactEditScreenTest.kt`

## 1. コンポーネント単体テスト (EmergencyContactEditContent)
**目的:** 入力フィールドの初期値、バリデーション連動、電話番号の動的切替を検証する。

| ID    | テスト項目       | 検証内容                                          |
|:------|:------------|:----------------------------------------------|
| CP-01 | 初期表示 (新規)   | 全ての項目が空（またはデフォルト優先度 99）で表示されること。              |
| CP-02 | 初期表示 (編集)   | 選択した連絡先の情報（病院名、番号等）が各フィールドに正しく反映されていること。      |
| CP-03 | バリデーション連動   | 施設名が空の場合、画面下の「保存」ボタンが非活性であること。                |
| CP-04 | 電話番号フォーカス切替 | 入力フィールドにフォーカスがある間はハイフンが消え、外れるとハイフン付きで表示されること。 |
| CP-05 | 種別プルダウン選択   | プルダウンから種別（家族、訪問看護等）を選択し、値が変更されること。            |

## 2. 画面全体の挙動・結合テスト
**目的:** 変更の検知、破棄確認ダイアログ、保存・キャンセルのフローを検証する。

| ID    | テスト項目         | 検証内容                                                     |
|:------|:--------------|:---------------------------------------------------------|
| BH-01 | キャンセル動作 (無変更) | 1 文字も入力していない状態で「キャンセル」または戻る操作をした際、ダイアログなしで即座に戻ること。       |
| BH-02 | 破棄確認ダイアログ     | 何かしら入力後に「キャンセル」または戻る操作をした際、「変更を破棄しますか？」の確認ダイアログが表示されること。 |
| BH-03 | 編集継続          | 破棄確認ダイアログで「編集を続ける」を選択した際、入力内容が維持されダイアログが閉じること。           |
| BH-04 | 破棄の確定         | 破棄確認ダイアログで「破棄して戻る」を選択した際、前の画面に戻ること。                      |
| BH-05 | 保存成功後の戻り      | 「保存」ボタンタップ後、保存が成功して前の画面（管理一覧）に自動で戻ること。                   |

## 3. テスト用タグ (testTag) 定義
- `EmergencyContact_SaveButton`: 保存ボタン
- `EmergencyContact_CancelButton`: キャンセルボタン
- `EmergencyContact_TypeDropdown`: 種別選択プルダウン
- `EmergencyContact_FacilityField`: 施設名入力欄
- `EmergencyContact_PhoneField`: 電話番号入力欄
- `EmergencyContact_DiscardDialog`: 破棄確認ダイアログ
