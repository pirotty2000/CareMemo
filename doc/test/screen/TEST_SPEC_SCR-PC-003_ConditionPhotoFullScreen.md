# テスト仕様書 - SCR-PC-003 ConditionPhotoFullScreen

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/condition/ConditionPhotoFullScreenTest.kt`

## 1. 概要
写真フル画面表示画面（ConditionPhotoFullScreen）における UI 描画、スワイプ・ズーム操作、および ViewModel の状態に応じたキャプション表示・ナビゲーションを検証する。

## 2. 表示テスト (Display)
**目的:** `UiState` に基づき、写真が全画面で正しく配置され、付随情報が表示されることを検証する。

| ID     | テスト項目     | 条件 (UiState)              | 期待結果                          |
|:-------|:----------|:--------------------------|:------------------------------|
| DSP-01 | 基本レイアウト   | 有効な写真リストあり                | 背景が黒色で、指定された写真が表示されていること      |
| DSP-02 | 初期表示写真の決定 | `initialPhotoId` 指定あり     | リストの中から該当する ID の写真が最初に表示されること |
| DSP-03 | キャプション表示  | 現在の写真にキャプションあり            | 画面下部にキャプションテキストが表示されること       |
| DSP-04 | キャプション非表示 | 現在の写真にキャプションなし            | キャプションエリアが表示されないこと            |
| DSP-05 | ローディング表示  | `isLoading = true` かつリスト空 | ローディングインジケータ（スピナー）が表示されること    |

## 3. 操作・インタラクションテスト (Interaction)
**目的:** ユーザーのジェスチャ（スワイプ・ズーム）が期待通りに動作することを検証する。

| ID     | テスト項目       | 操作           | 期待結果                                |
|:-------|:------------|:-------------|:------------------------------------|
| ACT-01 | 写真のスワイプ切り替え | 左右にスワイプ      | 表示される写真が前後へ切り替わり、キャプションも追従すること      |
| ACT-02 | ダブルタップズーム   | 写真をダブルタップ    | 画像が拡大され、スワイプ（Pagerのページ切り替え）が制限されること |
| ACT-03 | ズーム解除       | 拡大中に再度ダブルタップ | 画像が等倍に戻り、スワイプ操作が再び有効になること           |

## 4. ナビゲーション・副作用検証 (Navigation)
**目的:** 戻るボタン操作が正しく実行されることを検証する。

| ID     | テスト項目    | 操作        | 期待結果                                    |
|:-------|:---------|:----------|:----------------------------------------|
| NAV-01 | 画面終了（戻る） | 戻るボタンをタップ | `navController.popBackStack()` が実行されること |

## 5. テスト用タグ (testTag)
- `PhotoFullScreen_BackButton`: 戻るボタン
- `PhotoFullScreen_Pager`: 写真表示用 Pager
- `PhotoFullScreen_Image_{id}`: 各写真の画像コンテナ
- `PhotoFullScreen_Caption`: キャプション表示エリア
- `PhotoFullScreen_Spinner`: ローディングインジケータ
- `PhotoFullScreen_Container`: リスト空時のコンテナ
