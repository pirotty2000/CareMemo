# テスト仕様書 - SCR-S-003 DeleteOrRestorePerson

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/settings/DeleteOrRestorePersonScreenTest.kt`
    - `app/src/test/java/jp/mydns/fujiwara/carememo/viewmodel/DeleteOrRestorePersonViewModelTest.kt`

## 1. コンポーネント単体テスト (DeleteOrRestorePersonContent)
**目的:** 利用終了済みユーザーの一覧表示、選択操作、レイアウトの安定性を検証する。

| ID    | テスト項目      | 検証内容                                                 |
|:------|:-----------|:-----------------------------------------------------|
| CP-01 | 利用終了者リスト表示 | 利用終了状態のユーザーが一覧で表示されていること。                            |
| CP-02 | 空状態の表示     | 対象者がいない場合、専用のメッセージが表示されること。                          |
| CP-03 | 長大氏名のリスト表示 | 利用者の氏名が非常に長い場合でも、チェックボックスやテキストのレイアウトが崩れず、正しく選択できること。 |

## 2. 画面全体の挙動・結合テスト (DeleteOrRestorePerson)
**目的:** ユーザーの復帰処理および完全削除処理が正しく実行されることを検証する。

| ID    | テスト項目      | 検証内容                                                                               |
|:------|:-----------|:-----------------------------------------------------------------------------------|
| BH-01 | 利用者の復帰操作   | 復帰対象を選択して実行ボタンを押した際、確認ダイアログが表示され、実行後にリストから消えること。                                   |
| BH-02 | 利用者の完全削除   | 削除ボタン押下で警告ダイアログが表示され、「利用抹消」が成功した際にリストから消え、監査ログに正しく記録されること。                         |
| BH-03 | 復帰完了後の接続通知 | 復帰または抹消操作が成功した際、**親（SCR-S-001）およびその先のメイン画面まで更新を促すシグナルを伴って**、画面が終了（または終了準備が整う）すること。 |
| BH-04 | 画面の終了と戻り   | 戻る操作により、画面が閉じ（PopBackStack）、呼び出し元（SCR-S-001）へ戻ること。                                 |

## 3. ロジック・安全性テスト (DeleteOrRestorePersonViewModel)
**目的:** 重大なデータ操作を伴うため、例外発生時のロールバックやエラー通知が確実に行われることを検証する。

| ID    | テスト項目        | 検証内容                                                                                 |
|:------|:-------------|:-------------------------------------------------------------------------------------|
| LG-01 | 復帰/削除失敗時の安全性 | 処理中に例外が発生した際、`uiState.isLoading` が `false` になり、エラーダイアログが表示されること。                     |
| LG-02 | 設定の同期        | `UserSettingsRepository` のマスキング設定が変更された際、`uiState.isNameMaskingEnabled` に即座に反映されること。 |
| LG-03 | 状態の原子的な更新    | 選択解除や全選択を行った際、単一の `updateUiState` 呼び出しにより選択状態が原子的に反映されること。                           |
| LG-04 | 復帰バリデーション    | 利用者が未選択の状態で復帰を実行した際、`AppValidationException` がスローされ、エラーダイアログが表示されること。                |
| LG-05 | 抹消バリデーション    | 利用者が未選択の状態で抹消を実行した際、`AppValidationException` がスローされ、エラーダイアログが表示されること。                |

## 4. テスト用タグ (testTag) 定義
- `DeleteOrRestore_BackButton`: 戻るボタン
- `DeleteOrRestore_List`: 対象者リスト
- `DeleteOrRestore_Checkbox_{id}`: 各利用者の選択チェックボックス
- `DeleteOrRestore_ActionButton`: 復帰/抹消実行ボタン
