# テスト仕様書 - SCR-R-001 AlertReportScreen

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/report/AlertReportScreenTest.kt` (予定)

## 1. 概要
アラート・レポート画面の UI 表示およびインタラクションを検証する。
リストの視認性、重大度に応じた強調表示、および操作ボタンの反応を対象とする。

## 2. 表示検証
**目的:** アラート情報が正確かつ視認性高く表示されていることを検証する。

| ID     | テスト項目      | 条件                         | 期待結果                               |
|:-------|:-----------|:---------------------------|:-----------------------------------|
| DIS-01 | リスト項目の基本表示 | アラートが存在する状態                | 利用者名、日時、項目名、値、メッセージが表示されていること      |
| DIS-02 | 重大度による強調表示 | ALERT と WARNING の項目が混在する状態 | ALERT は赤系、WARNING は黄色系の背景色で表示されること |
| DIS-03 | 空状態の表示     | アラートが1件も存在しない状態            | 「アラートはありません」等のメッセージとアイコンが表示されること   |
| DIS-04 | ローディング表示   | データ取得中（Loading 状態）         | インジケータが表示されていること                   |

## 3. インタラクション検証
**目的:** 各種操作が ViewModel へ正しく伝達され、期待する挙動をすることを検証する。

| ID     | テスト項目      | 条件                | 期待結果                                |
|:-------|:-----------|:------------------|:------------------------------------|
| ACT-01 | リフレッシュボタン  | 更新アイコンをタップする      | ViewModel の `refreshReport` が呼ばれること |
| ACT-02 | フィルタタブ切り替え | 別のカテゴリタブを選択する     | リストの表示内容が切り替わること                    |
| ACT-03 | 項目タップによる遷移 | リスト内のカードをタップする    | 詳細画面への遷移イベントが発生すること                 |
| ACT-04 | 戻るボタン      | 上部バーの戻るアイコンをタップする | 画面が閉じられること                          |
