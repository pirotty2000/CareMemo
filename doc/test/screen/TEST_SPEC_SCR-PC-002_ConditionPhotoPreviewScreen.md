# テスト仕様書 - SCR-PC-002 ConditionPhotoPreviewScreen

- **対象テストコード:**

## 1. コンポーネント単体テスト (ConditionPhotoPreviewScreen)
**目的:** 渡された写真が正しくプレビュー表示され、編集UIが適切に配置されていることを検証する。

| ID    | テスト項目      | 検証内容                                          |
|:------|:-----------|:----------------------------------------------|
| CP-01 | 写真のプレビュー表示 | 親画面から渡された写真（または撮影直後の画像）が、画面中央に正しく表示されていること。   |
| CP-02 | キャプション入力欄  | テキスト入力フィールドが表示され、既存のキャプションがある場合はそれが反映されていること。 |
| CP-03 | 操作ボタンの配置   | 「保存」「削除」および戻るボタンが適切な位置に表示されていること。             |

## 2. 画面全体の挙動・結合テスト (ConditionPhotoPreviewScreen)
**目的:** キャプションの編集、保存、削除、および親画面への確実な結果返却を検証する。

| ID    | テスト項目        | 検証内容                                                            |
|:------|:-------------|:----------------------------------------------------------------|
| BH-01 | キャプションの編集    | テキスト入力によりキャプションの内容を変更でき、状態が維持されること。                             |
| BH-02 | 保存と戻り（接続の完了） | 保存ボタン押下で、**キャプションの変更内容を確定し、更新通知を伴って** `SCR-PC-001` へ戻ること。       |
| BH-03 | 写真の削除        | 削除ボタン押下で確認ダイアログが表示され、実行後に **「削除済み」の状態を伴って** `SCR-PC-001` へ戻ること。 |
| BH-04 | 変更破棄の戻る操作    | データを変更した状態で戻るボタンを押した際、破棄確認ダイアログが表示されること。                        |
| BH-05 | タイムアウト・不整合対策 | 写真データの読み込みに時間がかかる、あるいはデータが不正な場合でも、画面がフリーズせずエラー表示等で適切に処理されること。   |

## 3. テスト用タグ (testTag) 定義
- `PhotoPreview_Image`: プレビュー画像
- `PhotoPreview_CaptionInput`: キャプション入力欄
- `PhotoPreview_SaveButton`: 保存ボタン
- `PhotoPreview_DeleteButton`: 削除ボタン
- `PhotoPreview_BackButton`: 戻るボタン
