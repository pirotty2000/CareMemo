# テスト仕様書 - SCR-PH-003 GraphExpansionScreen

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/health/GraphExpansionScreenTest.kt`

## 1. 概要
健康記録のグラフ拡大表示画面（GraphExpansionScreen）における UI 描画、ランドスケープ表示の整合性、およびユーザーのジェスチャ操作（スクロール・ズーム）を検証する。
グラフデータの計算ロジック（HealthChartHelper等）は他のレイヤーで保証されているため、本テストでは UI 層の振る舞いに特化する。

## 2. 表示テスト (Display)
**目的:** `UiState` および渡されたパラメータに基づき、グラフおよびヘッダー情報が正しく描画されることを検証する。

| ID     | テスト項目     | 条件 (UiState)       | 期待結果                                  |
|:-------|:----------|:-------------------|:--------------------------------------|
| DSP-01 | 基本レイアウト   | 有効なデータあり           | ランドスケープ表示（横向き）で、戻るボタンとグラフリストが表示されること  |
| DSP-02 | ヘッダー情報の表示 | `Person` およびカテゴリ   | 利用者名（伏せ字設定対応）とカテゴリ名がタイトルに表示されていること    |
| DSP-03 | グラフの描画    | データあり              | カテゴリに応じた個数（血圧なら2つ等）のグラフカードがリスト表示されること |
| DSP-04 | 空状態の表示    | データ 0 件            | 「記録がありません」等のメッセージが表示されること             |
| DSP-05 | ローディング表示  | `isLoading = true` | 読み込み中を示すスピナーが表示されること                  |

## 3. 操作・インタラクションテスト (Interaction)
**目的:** ユーザーの入力やジェスチャ操作が期待通りに動作することを検証する。

| ID     | テスト項目        | 操作                  | 期待結果                                |
|:-------|:-------------|:--------------------|:------------------------------------|
| ACT-01 | グラフリストのスクロール | 画面を垂直（横持ち時の上下）にスワイプ | 複数のグラフがある場合、隠れているグラフまでスクロールできること    |
| ACT-02 | グラフ内ジェスチャ    | グラフ領域でスワイプ/ピンチ      | グラフの描画コンポーネント（LineChart）へ操作が伝達されること |

## 4. ナビゲーション・副作用検証 (Navigation)
**目的:** 画面遷移操作が正しく実行されることを検証する。

| ID     | テスト項目    | 操作        | 期待結果                                    |
|:-------|:---------|:----------|:----------------------------------------|
| NAV-01 | 画面終了（戻る） | 戻るボタンをタップ | `navController.popBackStack()` が実行されること |

## 5. テスト用タグ (testTag)
- `GraphExpansion_BackButton`: 戻るボタン
- `GraphExpansion_HeaderTitle`: ヘッダータイトル
- `GraphExpansion_GraphList`: グラフの LazyColumn
- `GraphExpansion_GraphCard_{index}`: 各グラフのカード
- `GraphExpansion_ChartView_{index}`: 各グラフの描画領域
- `GraphExpansion_Loading`: ローディング表示
- `GraphExpansion_EmptyState`: データなし表示
