# テスト仕様書 - SCR-PH-003 GraphExpansionScreen

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/health/GraphExpansionScreenTest.kt`

## 1. コンポーネント単体テスト (GraphExpansionScreen)
**目的:** グラフが画面全体に正しく表示され、補助情報（凡例、軸ラベル等）が適切に配置されていることを検証する。

| ID    | テスト項目      | 検証内容                                                    |
|:------|:-----------|:--------------------------------------------------------|
| CP-01 | 基本レイアウト表示  | 戻るボタンが左上に表示され、中央にグラフが大きく表示されていること。                      |
| CP-02 | グラフの描画内容   | 渡されたデータに基づき、折れ線グラフが正しく描画されていること。                        |
| CP-03 | 軸ラベルの表示    | X軸（日時）とY軸（値）のラベルが適切に表示されていること。                          |
| CP-04 | 受け取りデータの反映 | **親画面から渡された利用者ID**に基づいたデータが、`uiState` を通じて正しく描画されていること。 |
| CP-05 | 境界値：データ点数  | データが1点のみ、あるいは非常に高密度な場合でも、描画エラーが発生しないこと。                 |

## 2. 画面全体の挙動・結合テスト (GraphExpansionScreen)
**目的:** ユーザー操作（ピンチズーム、スクロール、戻るボタン）が正しく機能することを検証する。

| ID    | テスト項目    | 検証内容                                              |
|:------|:---------|:--------------------------------------------------|
| BH-01 | ピンチズーム操作 | ピンチアウトでグラフが拡大され、ピンチインで縮小されること。                    |
| BH-02 | スクロール操作  | 拡大中にドラッグ操作でグラフの表示範囲を移動できること。                      |
| BH-03 | 戻るボタンの動作 | 戻るボタンをタップした際、`onBack` コールバックが呼ばれること。              |
| BH-04 | 画面の終了と戻り | 戻るボタンの操作により、画面が正しく閉じ（PopBackStack）、呼び出し元へ遷移が戻ること。 |

## 3. テスト用タグ (testTag) 定義
- `GraphExpansion_BackButton`: 戻るボタン
- `GraphExpansion_ChartView`: グラフ描画エリア
