# テスト仕様書 - SCR-S-001 SettingsScreen

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/settings/SettingsScreenTest.kt`
    - `app/src/test/java/jp/mydns/fujiwara/carememo/viewmodel/SettingsViewModelTest.kt`

## 1. コンポーネント単体テスト (SettingsScreenContent)
**目的:** 設定画面の各項目が正しく表示され、スイッチやボタンが期待通りに配置されていることを検証する。

| ID    | テスト項目     | 検証内容                                          |
|:------|:----------|:----------------------------------------------|
| CP-01 | 基本レイアウト表示 | 画面タイトル「設定」が表示され、戻るボタンが存在すること。                 |
| CP-02 | 各種設定項目の表示 | 氏名伏せ字設定、バックアップ/リストアボタン、監査ログ遷移ボタンなどが表示されていること。 |

## 2. 画面全体の挙動・結合テスト (SettingsScreen)
**目的:** 設定変更の保存やバックアップ処理の開始などの挙動を検証する。

| ID    | テスト項目       | 検証内容                                                                        |
|:------|:------------|:----------------------------------------------------------------------------|
| BH-01 | 氏名伏せ字設定の変更  | スイッチを切り替えた際、設定が保存され、**画面を閉じる際に親（SCR-M-001）へ変更を通知する準備が整うこと。**                |
| BH-02 | バックアップ処理の開始 | バックアップ実行ボタンを押した際、確認ダイアログが表示され、実行後に成功メッセージが表示されること。                          |
| BH-03 | 操作ログへの遷移    | 監査ログ表示ボタンをタップした際、**SCR-S-002** へ正しく遷移すること。                                  |
| BH-04 | 操作ログからの戻り   | **SCR-S-002** から戻った際、設定画面の表示状態（スクロール位置等）が維持されていること。                         |
| BH-05 | 利用者管理への遷移   | 利用者管理メニューを選択した際、**SCR-S-003** へ正しく遷移すること。                                   |
| BH-06 | 利用者管理からの戻り  | **SCR-S-003** から戻った際、もし利用者の復帰等が行われていれば、**さらに親（SCR-M-001）へ更新を促す状態を伴って戻ること。** |

## 3. ロジック・安全性テスト (SettingsViewModel)
**目的:** 例外発生時も処理中フラグが適切に解除され、適切なエラーメッセージが表示されることを検証する。
本画面の各種処理（バックアップ、消去、整理等）は `safeLaunch` を通じて実行され、エラー発生時は `ViewModelCoroutineErrorHandler` により自動的にログ記録と通知が行われる。

| ID    | テスト項目            | 検証内容                                                                                   |
|:------|:-----------------|:---------------------------------------------------------------------------------------|
| LG-01 | バックアップ失敗時の安全性    | バックアップ中に例外（容量不足等）が発生した際、`uiState.isProcessing` が `false` になり、エラーダイアログが表示されること。         |
| LG-02 | 操作ログ消去失敗時の安全性    | 操作ログの全消去中に例外が発生した際、エラーダイアログが表示され、監査ログに ERROR が記録されること。                                 |
| LG-03 | 手動ローテーション失敗時の安全性 | ログの手動整理中に例外が発生した際、`uiState.isProcessing` が `false` になり、エラーダイアログが表示されること。               |
| LG-04 | 全データ消去失敗時の安全性    | 全データ消去中（写真削除含む）に例外が発生した際、**`IO_ERROR`** 等が記録され、`uiState.isProcessing` が `false` になること。 |
| LG-05 | 整合性チェック失敗時の安全性   | データベース整合性チェック中に例外が発生した際、`uiState.isProcessing` が `false` になり、エラーダイアログが表示されること。         |
| LG-06 | 利用終了者一覧取得の安全性    | 復帰用リストの取得（Flow）中に例外が発生した際、エラーダイアログが表示され、監査ログに ERROR が記録されること。                          |
| LG-07 | 設定の原子的な同期        | 複数の設定項目（UserSettingsRepository 由来）が、単一の `updateUiState` 呼び出しにより原子的に反映されること。            |
