# テスト仕様書 - SCR-S-002 AuditLogScreen

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/settings/AuditLogScreenTest.kt`
    - `app/src/test/java/jp/mydns/fujiwara/carememo/viewmodel/AuditLogViewModelTest.kt`

## 1. コンポーネント単体テスト (AuditLogScreenContent)
**目的:** 監査ログの一覧が正しく表示され、フィルタリングやソートの状態が反映されていることを検証する。

| ID    | テスト項目       | 検証内容                                                                                         |
|:------|:------------|:---------------------------------------------------------------------------------------------|
| CP-01 | ログリストの表示    | 取得された監査ログがリスト形式で正しく表示されていること。                                                                |
| CP-02 | 空状態の表示      | ログが存在しない場合、専用のメッセージが表示されること。                                                                 |
| CP-03 | フィルタ選択の表示   | 機能別、操作種別などのフィルタ選択肢が表示されていること。                                                                |
| CP-04 | 表示ラベルのマッピング | 各識別子が「利用終了（LOGICAL_DELETE）」「成功（SUCCESS）」「健康記録（PersonHealth）」などの**正しい日本語ラベルに変換されて表示されていること。** |
| CP-05 | 大量データの表示    | 多数のログが存在する場合でも、スクロールがスムーズであり、情報の欠落や重なりが発生しないこと。                                              |

## 2. 画面全体の挙動・結合テスト (AuditLogScreen)
**目的:** フィルタの変更やページング、戻る操作が正しく機能することを検証する。

| ID    | テスト項目        | 検証内容                                                   |
|:------|:-------------|:-------------------------------------------------------|
| BH-01 | フィルタの適用      | フィルタ条件を変更した際、ViewModelの再取得処理が呼ばれること。                   |
| BH-02 | 画面の終了と戻り     | 戻る操作（ボタンまたはジェスチャー）により、画面が正しく閉じ、呼び出し元（SCR-S-001）へ戻ること。  |
| BH-03 | 具体的ラベルでのフィルタ | フィルタチップから「利用者：新規登録・編集」や「成功」を選択した際、条件に合致するログのみが抽出されること。 |

## 3. ロジック・安全性テスト (AuditLogViewModel)
**目的:** 大量のデータ取得時や例外発生時も、画面がフリーズせずエラー状態が表示されることを検証する。

| ID    | テスト項目        | 検証内容                                                                  |
|:------|:-------------|:----------------------------------------------------------------------|
| LG-01 | データ取得失敗時の安全性 | ログ取得中に例外が発生した際、`uiState.isLoading` が `false` になり、監査ログ自体にもエラーが記録されること。 |
| LG-02 | 状態の原子的な更新    | フィルタ条件やソート順を変更した際、単一の `updateUiState` 呼び出しによりリストとフィルタ状態が原子的に反映されること。  |

## 4. テスト用タグ (testTag) 定義
- `AuditLogScreen_BackButton`: 戻るボタン
- `AuditLog_LogList`: ログリストコンテナ
- `AuditLog_FilterChips`: フィルタ選択エリア
