# テスト仕様書：一括入力フロー

本ドキュメントは、複数の健康記録（身長・体重、バイタル、血糖値等）を一つの画面でまとめて登録する「健康記録の一括入力」機能の操作フローと、登録後の各詳細画面におけるデータ整合性を検証するシナリオを定義します。

## 対象テストコード
`jp.mydns.fujiwara.carememo.ui.screens.scenario.BatchInputScenarioTest`

## 事前準備
1. テスト開始時に `ScenarioTestDataLoader` を使用して `androidTest/assets/backup.json` を DB にリストアする。
2. アプリを起動し、利用者一覧画面（SCR-M-001）を表示する。
