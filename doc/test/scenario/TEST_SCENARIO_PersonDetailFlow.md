# テスト仕様書：利用者詳細フロー (実データ検証)

本ドキュメントは、実機から抽出したサンプルデータ（`backup.json`）を用い、一覧から詳細画面（健康・所見・服薬）への遷移と、遷移後のデータ表示の整合性を検証するシナリオを定義します。

## 対象テストコード
`jp.mydns.fujiwara.carememo.ui.screens.scenario.PersonDetailScenarioTest`

## 事前準備
1. テスト開始時に `ScenarioTestDataLoader` を使用して `androidTest/assets/backup.json` を DB にリストアする。
2. アプリを起動し、利用者一覧画面（SCR-M-001）を表示する。

## 検証シナリオ：SCN-DET-01 (利用者「愛 植夫」の詳細確認)

| ステップ | 操作                           | NAV ID          | 検証項目 (期待結果)                                   |
|:-----|:-----------------------------|:----------------|:----------------------------------------------|
| 1    | 利用者一覧で「愛 植夫」が表示されていることを確認する。 | -               | 「愛 植夫」の項目が画面上に存在する。                           |
| 2    | 「愛 植夫」をタップし、ボトムシートを表示する。     | -               | クイックアクションメニューが表示される。                          |
| 3    | メニューの「身長・体重」を選択する。           | **NAV-PH-001**  | SCR-PH-001 に遷移し、履歴リストにレコードが表示されている。           |
| 4    | カテゴリバーの「バイタル」を選択する。          | -               | バイタル履歴が表示されている。                               |
| 5    | カテゴリバーの「血糖値」を選択する。           | -               | 血糖値履歴が表示されている。                                |
| 6    | カテゴリバーの「所見」を選択する。            | **NAV-COM-001** | SCR-PC-001 に遷移し、履歴リストに **12件** のレコードが表示されている。 |
| 7    | カテゴリバーの「服薬」を選択する。            | **NAV-COM-002** | SCR-PM-001 に遷移し、カレンダーまたは履歴にデータが反映されている。       |
| 8    | カテゴリバーの「健康」を選択する。            | **NAV-COM-003** | SCR-PH-001 に戻り、データが維持されている。                   |
| 9    | 「戻る」アイコンをタップする。              | -               | 利用者一覧画面（SCR-M-001）に戻る。                        |
