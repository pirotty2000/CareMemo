# テスト仕様書：データ登録フロー

本ドキュメントは、データの「登録・編集・保存」および「一覧への反映」という一連の副作用を伴う操作フローを検証するシナリオを定義します。
単体テストでは確認が困難な、画面遷移後のデータ整合性や非同期処理の完了待ちを主な検証対象とします。

## 対象テストコード
`jp.mydns.fujiwara.carememo.ui.screens.scenario.PersonRegistrationScenarioTest` (および `HealthRegistrationScenarioTest` 予定)

## 事前準備
1. テスト開始時に `ScenarioTestDataLoader` を使用して `androidTest/assets/backup.json` を DB にリストアする。
2. アプリを起動し、利用者一覧画面（SCR-M-001）を表示する。
