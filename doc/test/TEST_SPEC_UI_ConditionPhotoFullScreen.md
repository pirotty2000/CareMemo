# UI層テスト仕様書 - ConditionPhotoFullScreen (写真フル画面表示)

- **対象テストコード:**
    - `androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/condition/ConditionPhotoFullScreenTest.kt`

## 1. 画面表示テスト (ConditionPhotoFullScreen)
**目的:** 写真が画面いっぱいに正しく表示され、付随する情報（キャプション等）が適切に配置されていることを検証する。

| ID | テスト項目 | 検証内容 |
|:---|:---|:---|
| CP-01 | 基本レイアウト表示 | 背景が黒色であり、戻るボタンが左上に表示されていること。 |
| CP-02 | 初期写真の表示 | 指定された ID の写真が最初に表示されていること。 |
| CP-03 | キャプションの表示 | 写真にキャプションがある場合、画面下部に白文字で表示されること。 |
| CP-04 | キャプションのない表示 | 写真にキャプションがない場合、キャプションエリアが表示されないこと。 |
| CP-05 | ローディング表示 | 写真リスト取得中または空の場合、ローディングインジケーターが表示されること。 |

## 2. 画面全体の挙動・結合テスト (ConditionPhotoFullScreen)
**目的:** スワイプによる切り替えやズーム操作が、期待通りに動作することを検証する。

| ID | テスト項目 | 検証内容 |
|:---|:---|:---|
| BH-01 | 写真のスワイプ切り替え | 左右のスワイプ操作により、前後の写真に表示が切り替わること。 |
| BH-02 | ダブルタップズーム | 写真をダブルタップした際、拡大表示されること。再度ダブルタップで等倍に戻ること。 |
| BH-03 | ズーム中のスワイプ無効化 | 写真を拡大している間は、スワイプによる写真切り替え（Pagerのスクロール）が無効化されること。 |
| BH-04 | 戻る操作 | 戻るボタンをタップした際、`onBack` コールバックが呼ばれること。 |

## 3. テスト用タグ (testTag) 定義
- `PhotoFullScreen_BackButton`: 戻るボタン
- `PhotoFullScreen_Pager`: 写真表示用の Pager
- `PhotoFullScreen_Image_{id}`: 各写真の画像コンポーネント
- `PhotoFullScreen_Caption`: キャプション表示エリア
- `PhotoFullScreen_Loading`: ローディング表示

## 4. 実装状況
今回のUIテスト実装（`ConditionPhotoFullScreenTest.kt`）において、定義されたすべての項目が実装され、検証されている。
