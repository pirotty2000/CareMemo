# テスト仕様書 - DateTimeUtils

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/utils/DateTimeUtilsTest.kt`

## 1. 概要
アプリ全体で使用される日時操作・フォーマット用のユーティリティ `DateTimeUtils` の動作を検証する。
和暦（令和・平成・昭和等）の正確な付与、UTC 基準の生年月日正規化、年齢計算ロジック、および写真メタデータからのキャプション生成を主な対象とする。

## 2. フォーマットテスト (Formatting)
**目的:** 各種表示形式（和暦・曜日付き）への変換が、期待通りに行われることを検証する。

| ID     | テスト項目     | 入力値 (LocalDate/Instant) | 期待結果                                  |
|:-------|:----------|:------------------------|:--------------------------------------|
| FMT-01 | 日付ヘッダー形式  | 2023-10-27              | 「2023(令和5)年10月27日(金)」のように和暦と曜日が含まれること |
| FMT-02 | 年月ヘッダー形式  | 2023-10                 | 「2023(令和5)年10月」のように表示されること            |
| FMT-03 | 記録日時（フル）  | 2023-10-27 14:30:05     | 和暦・曜日・時分秒が含まれること                      |
| FMT-04 | グラフ用短縮形式  | 2023-10-27              | 「23/10/27」形式であること                     |
| FMT-05 | 時刻形式      | 14:30                   | 「HH:mm」形式で時刻のみが表示されること                |
| FMT-06 | 服薬ダイアログ形式 | 2023-10-27              | 「10月27日(金)」のように表示されること                |

## 3. 年齢・誕生日ロジックテスト (Birthday Logic)
**目的:** 誕生日に基づく計算（年齢、近いかどうかの判定）が正確に行われることを検証する。

| ID     | テスト項目    | 条件          | 期待結果                                  |
|:-------|:---------|:------------|:--------------------------------------|
| BDT-01 | 年齢計算     | 今日が誕生日の20年前 | 20歳と判定されること                           |
| BDT-02 | 年齢計算(前日) | 明日が誕生日の20年前 | 19歳と判定されること                           |
| BDT-03 | 誕生日直前判定  | 29日後が誕生日    | `isBirthdaySoon` が true を返すこと（30日指定時） |
| BDT-04 | 誕生日当日判定  | 今日が誕生日      | `isBirthdayToday` が true を返すこと        |
| BDT-05 | 誕生日表示形式  | 1950-01-01  | 「1950年1月1日 (昭和25年)」のように表示されること        |
| BDT-06 | 氏名編集用形式  | 1950-01-01  | 「昭和25年1月1日」のように和暦のみで表示されること           |

## 4. 正規化・UTC 処理テスト (Normalization)
**目的:** 保存データの整合性を保つための正規化処理が正しく行われることを検証する。

| ID     | テスト項目    | 入力値 (Instant) | 期待結果                                       |
|:-------|:---------|:--------------|:-------------------------------------------|
| NRM-01 | 誕生日の正規化  | 異なる時刻の同じ日付    | 時刻が 00:00:00Z に切り捨てられ、同一の Instant になること    |
| NRM-02 | タイムゾーン不変 | 任意のタイムゾーン     | 入力元に関わらず、日付部分を維持したまま UTC 00:00:00 に固定されること |

## 5. 写真キャプションテスト (Photo Caption)
**目的:** 写真の撮影日時に基づくデフォルトキャプションの生成を検証する。

| ID     | テスト項目    | 入力           | 期待結果                                    |
|:-------|:---------|:-------------|:----------------------------------------|
| CPT-01 | キャプション生成 | 特定の Instant  | 「yyyy/MM/dd HH:mm」形式の文字列が返されること         |
| CPT-02 | 撮影日時取得連携 | Context, URI | `ImageUtils` から日時を取得し、正しい形式でキャプション化すること |
