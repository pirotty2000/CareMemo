# テスト仕様書: ZipUtils

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/utils/ZipUtilsTest.kt`

## 1. 概要
`ZipUtils` は、Zip4jライブラリを使用してファイルやディレクトリの圧縮・解凍を行うユーティリティクラスである。
本テストでは、パスワード保護、進捗通知、および各種異常系（パスワード相違、ファイル破損、IOエラー等）における例外送出の挙動を検証する。

## 2. テスト環境
- ユニットテスト: JUnit 4, MockK
- 統合テスト: Android Instrumented Test (実際のファイルシステムを使用した圧縮・解凍操作)

## 3. テスト項目

## 4. エラーハンドリングの検証（監査ログ連携）
本ユーティリティからスローされた例外は、ViewModel の `safeLaunch` を通じて以下の通り処理される必要がある。
1. `IOException` 発生時、監査ログの `resultType` に `IO_ERROR` が記録されること。
2. パスワード不一致等のバリデーションエラー時、`VALIDATION_ERROR` (または適切な識別子) が記録されること。
3. `details` にスタックトレースや原因メッセージが含まれること。
