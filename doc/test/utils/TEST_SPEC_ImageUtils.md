# テスト仕様書: ImageUtils

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/utils/ImageUtilsTest.kt`

## 1. 概要
`ImageUtils` は、画像のリサイズ、回転補正、サムネイル作成、および物理ファイル操作を担当するユーティリティクラスである。
本テストでは、画像処理の正確性に加え、エラーハンドリング（例外の送出）が設計通りに行われるかを検証する。

## 2. テスト環境
- ユニットテスト: JUnit 4, MockK
- 統合テスト: Android Instrumented Test (物理/エミュレータ上のディスク操作を含む)

## 3. テスト項目

### 3.1. 画像処理 (processAndSaveImage)
| ID     | テスト項目  | 入力値・条件                              | 期待される結果                           | 備考     |
|:-------|:-------|:------------------------------------|:----------------------------------|:-------|
| IMG-01 | 正常保存   | 有効な画像URI                            | メイン画像とサムネイルが保存され、ファイル名のペアが返されること。 |        |
| IMG-02 | 回転補正   | Exif回転情報(90度)を持つ画像                  | 保存された画像が正しく回転補正されていること。           |        |
| IMG-03 | リサイズ   | AppThresholds.IMAGE_MAX_SIZE を超える画像 | 指定サイズ以下にリサイズされていること。              |        |
| IMG-04 | 読み込み失敗 | 存在しないURI、または破損した画像                  | **IOException** がスローされること。        | [強化項目] |
| IMG-05 | 保存失敗   | ディスクフル、または書き込み権限なし                  | **IOException** がスローされること。        | [強化項目] |

## 4. エラーハンドリングの検証（監査ログ連携）
本ユーティリティからスローされた例外は、ViewModel の `safeLaunch` を通じて以下の通り処理される必要がある。
1. `IOException` 発生時、監査ログの `resultType` に `IO_ERROR` が記録されること。
2. `details` に例外のメッセージ（原因）が含まれること。
