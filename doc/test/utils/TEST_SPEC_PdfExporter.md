# テスト仕様書: PdfExporter

- **対象テストコード:**
    - `app/src/androidTest/java/jp/mydns/fujiwara/carememo/utils/PdfExporterTest.kt`

## 1. 概要
`PdfExporter` は、アプリ内の健康記録、所見メモ、服薬記録等のデータをA4サイズのPDFとして生成し、共有するユーティリティクラスである。
本テストでは、各種カテゴリの描画の正確性に加え、ファイル操作や共有プロセスでのエラーハンドリングを検証する。

## 2. テスト環境
- ユニットテスト: JUnit 4, MockK
- 統合テスト: Android Instrumented Test (PdfDocument, Canvas, および物理ファイル操作を含む)

## 4. エラーハンドリングの検証（監査ログ連携）
本ユーティリティからスローされた例外は、ViewModel の `safeLaunch` を通じて以下の通り処理される必要がある。
1. `IOException` 発生時、監査ログの `resultType` に `IO_ERROR` が記録されること。
2. その他のシステムエラー発生時、監査ログの `resultType` に `OTHER_ERROR` が記録されること。
3. `details` にエラーの具体的な原因（メッセージ）が含まれること。
