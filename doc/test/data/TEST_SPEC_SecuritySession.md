# テスト仕様書 - SecuritySession

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/data/SecuritySessionTest.kt`

## 1. 概要
アプリケーションの実行セッション中のみ保持されるセキュリティ状態の管理を検証する。
このコンポーネントは永続化を伴わず、メモリ上でのフラグ制御が正確に行われることを対象とする。

## 2. セッション状態テスト
**目的:** フラグの初期値、設定、およびリセットが意図通りに動作することを検証する。

| ID     | テスト項目       | 検証内容                    | 期待結果                             |
|:-------|:------------|:------------------------|:---------------------------------|
| SES-01 | 初期状態        | インスタンス生成直後の値参照          | `isLockBypassed` が `false` であること |
| SES-02 | バイパスON      | `isLockBypassed` への `true` 代入 | 値が `true` に保持されること              |
| SES-03 | バイパスOFF/消費 | `isLockBypassed` への `false` 代入 | 値が `false` に戻ること               |
