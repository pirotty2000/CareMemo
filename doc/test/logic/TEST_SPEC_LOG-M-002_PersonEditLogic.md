# テスト仕様書 - LOG-M-002 PersonEditLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/feature/PersonEditLogicTest.kt`

## 1. 変更検知テスト (isChanged)
**目的:** 利用者の基本情報が初期状態から変更されたかを正しく判定できることを検証する。

| ID     | テスト項目    | 条件 (入力)                | 期待結果 (戻り値) |
|:-------|:---------|:-----------------------|:----------:|
| CHG-01 | 変更なし（新規） | 全てのフィールドがデフォルト値        |  `false`   |
| CHG-02 | 入力あり（新規） | いずれかのフィールドに入力あり        |   `true`   |
| CHG-03 | 変更なし（更新） | 全てのフィールドが初期 Entity と一致 |  `false`   |
| CHG-04 | 氏名の変更    | 氏名（姓または名）を変更           |   `true`   |
| CHG-05 | 生年月日の変更  | 生年月日（元号、年、月、日のいずれか）を変更 |   `true`   |
| CHG-06 | メモの変更    | 備考欄を変更                 |   `true`   |

## 2. バリデーションテスト (validate)
**目的:** 入力内容の妥当性をビジネスルールに則って判定し、適切な「事実」を返せることを検証する。

| ID     | テスト項目     | 条件 (入力)            | 期待結果 (Enum)            |
|:-------|:----------|:-------------------|:-----------------------|
| VAL-01 | 正常な入力     | 全ての必須項目が適切に入力されている | `SUCCESS`              |
| VAL-02 | 姓が空       | 苗字が空文字または空白のみ      | `EMPTY_LAST_NAME`      |
| VAL-03 | 名が空       | 名前が空文字または空白のみ      | `EMPTY_FIRST_NAME`     |
| VAL-04 | ふりがな（姓）が空 | 苗字（ふりがな）が空文字       | `EMPTY_LAST_FURIGANA`  |
| VAL-05 | ふりがな（名）が空 | 名前（ふりがな）が空文字       | `EMPTY_FIRST_FURIGANA` |
| VAL-06 | 生年月日が不正   | 存在しない日付（例：2月30日）   | `INVALID_BIRTHDAY`     |

## 3. Entity 生成テスト (createPerson)
**目的:** UI状態からデータベース保存用の Entity が正しく構築されることを検証する。

| ID     | テスト項目      | 検証内容                                                    |
|:-------|:-----------|:--------------------------------------------------------|
| CRT-01 | プロパティの詰め替え | 各フィールドが Entity の対応するプロパティに正しくセットされること。                  |
| CRT-02 | 空白のトリミング   | 氏名、ふりがな、備考の前後にある空白が `trim()` されて保存用データになること。            |
| CRT-03 | IDの維持      | 更新時（initial != null）に元の ID が正しく引き継がれること。                |
| CRT-04 | 不正データでの例外  | 不正な生年月日の状態で呼び出した際、`IllegalArgumentException` がスローされること。 |
