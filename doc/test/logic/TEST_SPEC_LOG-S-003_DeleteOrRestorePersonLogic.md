## 1. 概要

（現時点では主に UiState の初期状態やプロパティの整合性を検証する）

## 2. UI状態テスト (UiState)
**目的:** 画面全体の表示状態を保持する `DeleteOrRestorePersonUiState` が、初期値や更新時に正しく振る舞うことを検証する。

| ID    | テスト項目      | 検証内容                                             |
|:------|:-----------|:-------------------------------------------------|
| UI-01 | 初期状態の整合性   | モードが `RESTORE`、リストが空、選択中が空、読み込み中が `false` であること。 |
| UI-02 | 選択状態の追加・削除 | 特定の ID を Set に追加したり削除したりした際の整合性が保たれること。          |
| UI-03 | マスキング設定の反映 | `isNameMaskingEnabled` が更新された際、正しく保持されること。       |

## 3. モード・制約テスト
**目的:** 操作モード（復帰・抹消）の変更が正しく状態に反映されることを検証する。

|:-------|:------------|:----------|:----------------------|
| MOD-01 | 抹消モードへの切り替え | `DELETE`  | モードが `DELETE` になること。  |
| MOD-02 | 復帰モードへの切り替え | `RESTORE` | モードが `RESTORE` になること。 |
