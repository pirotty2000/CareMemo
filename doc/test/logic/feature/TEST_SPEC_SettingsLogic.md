# テスト仕様書 - SettingsLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/feature/SettingsLogicTest.kt`

## 1. 概要
設定画面、バックアップ管理、およびシステムメンテナンスに関するドメインロジックの正確性を検証する。
特にファイル形式のバイナリ検証、バージョン互換性判定（開発者モードを含む）、および表示用ラベル生成を対象とする。

## 2. ファイル形式判定テスト (validateImportFormat)
**目的:** インポートファイルのヘッダー（マジックナンバー）から、Zip 形式であるかを正しく判定できることを検証する。

| ID     | テスト項目      | 条件 (入力：ByteArray)                 | 期待結果 (Enum) |
|:-------|:-----------|:----------------------------------|:------------|
| FMT-01 | 正しい Zip 形式 | `[0x50, 0x4B, 0x03, 0x04]` (PK..) | `SUCCESS`   |
| FMT-02 | ヘッダー不足     | `[0x50, 0x4B]` (2バイトのみ)           | `NOT_A_ZIP` |
| FMT-03 | 不正な形式      | `[0x00, 0x00, 0x00, 0x00]`        | `NOT_A_ZIP` |

## 3. バージョン互換性テスト (validateVersion)
**目的:** バックアップデータとアプリバージョンの互換性を、開発者モードの設定を含めて正しく判定できることを検証する。

| ID     | テスト項目     | 条件 (backup, current, devMode) | 期待結果 (Enum)    |
|:-------|:----------|:------------------------------|:---------------|
| VER-01 | 同一バージョン   | 100, 100, false               | `SUCCESS`      |
| VER-02 | 下位互換あり    | 90, 100, false                | `SUCCESS`      |
| VER-03 | 上位バージョン不可 | 110, 100, false               | `INCOMPATIBLE` |
| VER-04 | 開発者モード強制  | 110, 100, **true**            | `SUCCESS`      |

## 4. 容量・書き込み判定テスト (validateStorageSpace)
**目的:** 要求されたサイズに対して空き容量が十分であるかを正しく判定できることを検証する。

| ID     | テスト項目   | 条件 (available, required) | 期待結果 (Enum)          |
|:-------|:--------|:-------------------------|:---------------------|
| SPC-01 | 十分な空きあり | 100MB, 50MB              | `SUCCESS`            |
| SPC-02 | 空き不足    | 40MB, 50MB               | `INSUFFICIENT_SPACE` |
| SPC-03 | 境界値（一致） | 50MB, 50MB               | `SUCCESS`            |

## 5. 開発者モード判定テスト (shouldEnableDeveloperMode)
**目的:** 規定のタップ数に基づき、開発者モードを有効にすべきかを正しく判定できることを検証する。

| ID     | テスト項目 | 条件 (入力：tapCount) |  期待結果   |
|:-------|:------|:-----------------|:-------:|
| DEV-01 | 閾値未満  | 6 (閾値: 7)        | `false` |
| DEV-02 | 閾値到達  | 7                | `true`  |
| DEV-03 | 閾値超過  | 10               | `true`  |

## 6. 表示ラベル生成テスト (getTimeoutLabel / getRetentionLabel)
**目的:** 設定値（数値）から、UI で表示する適切な日本語ラベルが生成されることを検証する。

| ID     | テスト項目      | 条件 (入力) | 期待結果 (出力) |
|:-------|:-----------|:--------|:----------|
| LBL-01 | ロック時間(即時)  | 0       | 「即時」      |
| LBL-02 | ロック時間(しない) | -1      | 「ロックしない」  |
| LBL-03 | ロック時間(数値)  | 5       | 「5分」      |
| LBL-04 | 保持期間(残さない) | 0       | 「残さない」    |
| LBL-05 | 保持期間(1週間)  | 7       | 「1週間」     |
| LBL-06 | 保持期間(1ヶ月)  | 30      | 「1ヶ月」     |
| LBL-07 | 保持期間(その他)  | 100     | 「100日間」   |
