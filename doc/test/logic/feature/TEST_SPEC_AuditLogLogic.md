# テスト仕様書 - AuditLogLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/feature/AuditLogLogicTest.kt`

## 1. 概要
操作ログ（監査ログ）画面における、表示データの絞り込み、並べ替え、およびフィルター選択肢の抽出ロジックの正確性を検証する。

## 2. 監査ログフィルタリングテスト (filterAndSortLogs)
**目的:** 指定された条件（機能名、結果）による絞り込みと、日時に基づくソートが正しく行われることを検証する。

| ID    | テスト項目  | 条件 (入力)                              | 期待結果                  |
|:------|:-------|:-------------------------------------|:----------------------|
| LG-01 | フィルタなし | feature=null, result=null, asc=false | 全件が降順（新しい順）で返されること    |
| LG-02 | 機能フィルタ | feature="Settings"                   | 指定された機能のログのみ抽出されること   |
| LG-03 | 結果フィルタ | result="SUCCESS"                     | 指定された結果のログのみ抽出されること   |
| LG-04 | 複合フィルタ | feature="Settings", result="SUCCESS" | 両方の条件に合致するログのみ抽出されること |
| LG-05 | 昇順ソート  | ascending=true                       | 日時の昇順（古い順）でソートされること   |
| LG-06 | 該当なし   | 存在しない機能名を指定                          | 空リストが返されること           |

## 3. 選択肢抽出テスト (extractAvailableFeatures / extractAvailableResults)
**目的:** ログリストから、フィルタドロップダウンに使用するユニークかつソート済みの選択肢が正しく抽出されることを検証する。

| ID    | テスト項目   | 検証内容                     | 期待結果              |
|:------|:--------|:-------------------------|:------------------|
| EX-01 | 機能一覧の抽出 | 複数機能が混在するログからユニークなリストを抽出 | 重複なし・ソート済みの機能名リスト |
| EX-02 | 結果一覧の抽出 | 複数結果が混在するログからユニークなリストを抽出 | 重複なし・ソート済みの結果リスト  |
