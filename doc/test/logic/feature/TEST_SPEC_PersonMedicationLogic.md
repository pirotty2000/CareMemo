# テスト仕様書 - PersonMedicationLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/feature/PersonMedicationLogicTest.kt`

## 1. 概要
服薬管理画面におけるデータの集計および UI 状態（UiState）への変換ロジックの正確性を検証する。
特に、カレンダー表示や履歴テーブルでの効率的なデータ取得を可能にするためのグルーピングロジックを対象とする。

## 2. UI状態変換テスト (groupRecordsByDate)
**目的:** 服薬履歴のリストを、日付（"yyyy-MM-dd"）をキーとしたマップに正しく集計できることを検証する。

| ID    | テスト項目    | 条件 (入力)            | 期待結果                      |
|:------|:---------|:-------------------|:--------------------------|
| UI-01 | 履歴のグループ化 | 同一日の複数スロット記録を含むリスト | 日付文字列をキーとしたマップに正しく分類されること |
| UI-02 | 空リストの処理  | 空のレコードリスト          | 空のマップが返されること              |

## 3. UI状態テスト (UiState)
**目的:** 画面表示状態を保持する `PersonMedicationUiState` が、設計通りの初期値で生成されることを検証する。

| ID     | テスト項目    | 検証内容             |                期待結果                |
|:-------|:---------|:-----------------|:----------------------------------:|
| STA-01 | 初期状態の整合性 | デフォルトコンストラクタでの生成 | カテゴリが `MEDICATION`、各リスト/マップが空であること |
