# テスト仕様書 - PersonConditionLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/feature/PersonConditionLogicTest.kt`

## 1. 概要
所見メモ（カテゴリB）画面における入力状態の判定、バリデーション、および Entity 生成ロジックの正確性を検証する。

## 2. 変更検知テスト (isChanged)
**目的:** 画面上の入力内容が初期状態（スナップショット）から変更されたかを正しく判定できることを検証する。

| ID     | テスト項目      | 条件 (入力)                 |  期待結果   |
|:-------|:-----------|:------------------------|:-------:|
| CHG-01 | 変更なし       | 全てのフィールドがスナップショットと一致    | `false` |
| CHG-02 | タイトルの変更    | タイトルのみ異なる内容を入力          | `true`  |
| CHG-03 | 内容の変更      | 所見内容のみ異なる内容を入力          | `true`  |
| CHG-04 | 記録者の変更     | 記録者のみ異なる内容を入力           | `true`  |
| CHG-05 | 記録日時の変更    | 記録日時のみ異なる日時を選択          | `true`  |
| CHG-06 | スナップショットなし | `snapshot` が `null` の場合 | `false` |

## 3. バリデーションテスト (validate / isValid)
**目的:** 入力内容の妥当性をビジネスルールに則って判定し、適切な「事実」を返せることを検証する。

| ID     | テスト項目     | 条件 (入力)             | 期待結果 (Enum)          | isValid |
|:-------|:----------|:--------------------|:---------------------|:-------:|
| VAL-01 | 正常な入力     | 全ての必須項目が適切に入力されている  | `SUCCESS`            | `true`  |
| VAL-02 | 内容が空      | 所見内容が空文字または空白のみ     | `EMPTY_CONDITION`    | `false` |
| VAL-03 | 記録者が空     | 記録者が空文字または空白のみ      | `EMPTY_AUTHOR`       | `false` |
| VAL-04 | 日時が未指定    | 記録日時が `null`        | `INVALID_TIME`       | `false` |
| VAL-05 | 本文文字数超過   | 所見内容が制限文字数（1000文字）超 | `CONDITION_TOO_LONG` | `false` |
| VAL-06 | タイトル文字数超過 | タイトルが制限文字数（100文字）超  | `TITLE_TOO_LONG`     | `false` |

## 4. Entity 生成テスト (createRecord)
**目的:** UI入力状態からデータベース保存用の Entity が正しく構築・正規化されることを検証する。

| ID     | テスト項目      | 検証内容                         | 期待結果                       |
|:-------|:-----------|:-----------------------------|:---------------------------|
| CRT-01 | プロパティの詰め替え | 各フィールドが Entity に正しくセットされること  | 一致すること                     |
| CRT-02 | 空白のトリミング   | 文字列項目の前後にある空白が除去されること        | `trim()` 済みであること           |
| CRT-03 | 新規IDの発行    | ID が新規用の場合、Logic 内で新しい UUID が発行されること | 有効な UUID であること             |
| CRT-04 | 既存IDの維持    | ID が指定されている場合、その ID が維持されること | 指定した ID と一致すること            |
| CRT-05 | 不正データでの例外  | 記録日時が `null` の状態で呼び出し        | `IllegalArgumentException` |
