# テスト仕様書 - AlertReportLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/feature/AlertReportLogicTest.kt`

## 1. 概要
健康データ（バイタル、身長・体重、血糖値等）から異常値をスキャンし、`AlertItem` に変換する抽出エンジンのロジックを検証する。
判定アルゴリズム（`HealthLogic` / `AlertLogic`）の呼び出しと、期間フィルタ、マスク処理の整合性を対象とする。

## 2. アラート抽出テスト (scanAlerts)
**目的:** 各カテゴリの最新データから異常値が正しく抽出され、適切な属性を持つ `AlertItem` が生成されることを検証する。

| ID      | テスト項目      | 条件 (入力データ)                        | 期待結果                     |
|:--------|:-----------|:----------------------------------|:-------------------------|
| SCAN-01 | 異常バイタルの抽出  | 血圧(150/95) 等の ALERT レベルのバイタルデータ記録 | リストに含まれ、重大度が ALERT であること |
| SCAN-02 | 急激な体重減少の抽出 | 前回比 -3.0kg 以上の体重データ記録             | メッセージに「急激な体重減少」が含まれること   |
| SCAN-03 | BMI異常の抽出   | BMI 30 以上（肥満2度）の体重データ記録           | 重大度が WARNING 以上で抽出されること  |
| SCAN-04 | 血糖値異常の抽出   | 血糖値 126 以上 または 70 未満のデータ記録        | 正しい判定メッセージと重大度が設定されること   |
| SCAN-05 | 正常データの除外   | 全ての項目が NORMAL 範囲内のデータ記録           | リストが空であること               |
| SCAN-06 | 論理削除データの除外 | `deletedAt` が設定されている異常データ記録       | リストに含まれないこと              |
| SCAN-07 | 最新データのみの抽出 | 同一利用者に複数の異常データ（新・旧）がある場合          | 最新の1件のみが判定対象となること        |

## 3. フィルタ・加工テスト
**目的:** 期間指定や名前のマスク処理が仕様通りに適用されることを検証する。

| ID     | テスト項目      | 条件 (入力データ)                     | 期待結果                              |
|:-------|:-----------|:-------------------------------|:----------------------------------|
| FLT-01 | 期間フィルタ（有効） | `sinceDays=30` かつ 10日前の異常データ記録 | リストに含まれること                        |
| FLT-02 | 期間フィルタ（除外） | `sinceDays=30` かつ 40日前の異常データ記録 | リストに含まれないこと                       |
| FLT-03 | 体重減少の期間外比較 | 最新(期間内) vs 前回(期間外) で減少条件成立     | 比較対象が期間外でも、最新が期間内ならアラート抽出されること    |
| MSK-01 | 名前マスクの適用   | `isNameMaskingEnabled=true`    | `personName` が交互にマスクされた形式であること    |
| MSK-02 | 名前マスクの解除   | `isNameMaskingEnabled=false`   | `personName` がフルネーム（漢字）のままであること   |
| SRT-01 | 日時降順ソート    | 異なる日時のアラートが複数発生                | `recordTime` の降順（新しい順）でソートされていること |
