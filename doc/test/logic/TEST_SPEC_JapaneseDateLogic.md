# テスト仕様書：JapaneseDateLogic (TEST_SPEC_JapaneseDateLogic.md)

## 1. 概要
`JapaneseDateLogic` クラスにおける、西暦と和暦の相互変換、および日付の妥当性判定ロジックの正確性を検証する。

## 2. テスト対象メソッド

- `toJapaneseDate(date: LocalDate)`: 西暦から和暦（元号・年）への変換
- `toLocalDate(era: BirthEra, year: Int, month: Int, day: Int)`: 和暦から西暦への変換
- `isValid(era: BirthEra, year: Int, month: Int, day: Int)`: 日付の妥当性判定
- `formatYear(year: Int)`: 年の表示形式変換（1年を「元年」とするか等）
