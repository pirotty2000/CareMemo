# テスト仕様書 - AlertLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/common/AlertLogicTest.kt`

## 1. 概要
健康データから時系列的な変化（急激な体重減少など）を判定するロジックを検証する。

## 2. 体重減少判定テスト (evaluateWeightLoss)
**目的:** 前回値と比較して、規定の閾値（-3.0kg）以上の減少があった場合に正しくアラートが発火することを検証する。

| ID     | テスト項目       | 条件 (入力データ)                      | 期待結果                                |
|:-------|:------------|:--------------------------------|:------------------------------------|
| WTL-01 | 閾値ぴったりの減少   | 前回 60.0kg -> 今回 57.0kg (-3.0kg) | レベルが ALERT、メッセージに "-3.0 kg" が含まれること |
| WTL-02 | 閾値を超える減少    | 前回 60.0kg -> 今回 56.5kg (-3.5kg) | レベルが ALERT、メッセージに "-3.5 kg" が含まれること |
| WTL-03 | 閾値未満の減少     | 前回 60.0kg -> 今回 57.1kg (-2.9kg) | レベルが NORMAL であること                   |
| WTL-04 | 体重の増加       | 前回 60.0kg -> 今回 61.0kg (+1.0kg) | レベルが NORMAL であること                   |
| WTL-05 | 無効な入力（null） | 今回または前回が null                   | レベルが NORMAL であること                   |
