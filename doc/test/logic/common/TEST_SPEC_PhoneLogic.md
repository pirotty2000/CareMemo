# テスト仕様書 - PhoneLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/common/PhoneLogicTest.kt`

## 1. 概要
日本の電話番号体系に基づいたハイフン挿入ロジックの正確性を検証する。
本クラスは UI (VisualTransformation) および Mapping レイヤーの共通脳として機能するため、0120 等の特殊な番号帯を含め、網羅的に検証する。

## 2. 電話番号整形テスト (formatPhoneNumber)
**目的:** 数字列から表示用のハイフン付き形式への変換が、仕様通りに行われることを検証する。

| ID     | テスト項目       | 条件 (入力)         | 期待結果 (出力)         | 備考       |
|:-------|:------------|:----------------|:------------------|:---------|
| FMT-01 | 携帯電話 (11桁)  | `"09012345678"` | `"090-1234-5678"` | 3-4-4 形式 |
| FMT-02 | 東京・市外局番2桁   | `"0312345678"`  | `"03-1234-5678"`  | 2-4-4 形式 |
| FMT-03 | 大阪・市外局番2桁   | `"0612345678"`  | `"06-1234-5678"`  | 2-4-4 形式 |
| FMT-04 | 一般市外局番 (3桁) | `"0481234567"`  | `"048-123-4567"`  | 3-3-4 形式 |
| FMT-05 | フリーダイヤル     | `"0120000000"`  | `"0120-000-000"`  | 4-3-3 形式 |
| FMT-06 | フリーコール      | `"0800000000"`  | `"0800-000-000"`  | 4-3-3 形式 |
| FMT-07 | ナビダイヤル      | `"0570000000"`  | `"0570-000-000"`  | 4-3-3 形式 |
| FMT-08 | 特殊桁数（整形なし）  | `"12345"`       | `"12345"`         | そのまま返す   |
| FMT-09 | 空文字・null    | `""` / `null`   | `null`            |          |

## 3. ハイフン位置判定テスト (getHyphenPositions)
**目的:** VisualTransformation 等で使用する、ハイフン挿入位置（インデックス）のリストが正しく返されることを検証する。

| ID     | テスト項目     | 条件 (入力)         | 期待結果 (List) |
|:-------|:----------|:----------------|:------------|
| POS-01 | 携帯電話      | `"09012345678"` | `[2, 6]`    |
| POS-02 | 東京・市外局番2桁 | `"0312345678"`  | `[1, 5]`    |
| POS-03 | フリーダイヤル   | `"0120000000"`  | `[3, 6]`    |
| POS-04 | 一般固定電話    | `"0481234567"`  | `[2, 5]`    |
