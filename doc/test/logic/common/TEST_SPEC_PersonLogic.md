# テスト仕様書 - PersonLogic

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/logic/common/PersonLogicTest.kt`

## 1. 利用者データのクレンジングテスト (cleansePersonData)
**目的:** インポート等で渡された利用者リストに対し、生年月日の正規化および重複回避処理が正しく行われることを検証する。

### 1.1 生年月日の正規化
| ID     | テスト項目     | 条件 (入力)                         | 期待結果                                |
|:-------|:----------|:--------------------------------|:------------------------------------|
| CLN-01 | 日時情報の切り捨て | 生年月日に時分秒が含まれる (例: 15:30:00 UTC) | 生年月日が **00:00:00 UTC** に正規化されていること。 |

### 1.2 重複回避（識別子付与）
| ID     | テスト項目        | 条件 (入力)                                     | 期待結果                                                         |
|:-------|:-------------|:--------------------------------------------|:-------------------------------------------------------------|
| CLN-02 | 重複時のサフィックス付与 | 姓、名、生年月日、メモが完全に一致するデータが2件以上存在する。            | 2件目以降のデータのメモに、指定された形式のサフィックス（識別子）が付与されていること。                 |
| CLN-03 | メモ文字数制限の遵守   | 重複が発生し、かつメモが最大文字数（255文字）に近い。                | サフィックス付与後の文字数が **255文字以内** に収まっており、必要に応じて元のメモが末尾でカットされていること。 |
| CLN-04 | 非重複時の維持      | 同姓同名だが生年月日が異なる、あるいはメモが異なるなど、ユニーク制約に抵触しない場合。 | メモの内容が変更されず、そのまま維持されていること。                                   |
| CLN-05 | 空のメモへの付与     | メモが空の状態で重複が発生した。                            | メモの先頭からサフィックスが付与されていること。                                     |
