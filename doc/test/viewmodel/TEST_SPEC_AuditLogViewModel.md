# テスト仕様書 - AuditLogViewModel

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/viewmodel/AuditLogViewModelTest.kt`

## 1. 概要
操作ログ（監査ログ）画面における、データの読み込み、フィルタリング、ソートを伴う UI 状態管理、および画面遷移イベントの発行を検証する。
`AuditLogRepository` からのデータ購読と、`AuditLogLogic` による加工の組み合わせが正しく行われるかを対象とする。

## 2. データ読み込みテスト (Init / Load)
**目的:** 画面起動時やデータ更新時に、適切に State が更新されることを検証する。

| ID    | テスト項目       | 検証内容                | 期待結果                                                 |
|:------|:------------|:--------------------|:-----------------------------------------------------|
| RD-01 | 初期ロード成功     | 起動時にリポジトリからログを取得    | `filteredLogs` および `availableFeatures` 等が正しくセットされること |
| RD-02 | ロード中状態の管理   | データ取得開始から完了まで       | `isLoading` が適切に true -> false と遷移すること               |
| RD-03 | 読み込み失敗時の安全性 | リポジトリの Flow が例外をスロー | `isLoading` が解除され、監査ログにエラーが記録されること                   |

## 3. フィルタリング・ソートテスト (Filter / Sort)
**目的:** ユーザーによるフィルタ操作やソート切り替えが、表示データに正しく反映されることを検証する。

| ID     | テスト項目    | 条件 (操作)                  | 期待結果                                             |
|:-------|:---------|:-------------------------|:-------------------------------------------------|
| FLT-01 | 機能フィルタ変更 | `setFeatureFilter` を呼び出し | `selectedFeature` が更新され、`filteredLogs` が絞り込まれること |
| FLT-02 | 結果フィルタ変更 | `setResultFilter` を呼び出し  | `selectedResult` が更新され、`filteredLogs` が絞り込まれること  |
| SRT-01 | ソート順切り替え | `toggleSortOrder` を呼び出し  | `isAscending` が反転し、`filteredLogs` の並び順が変わること     |
| CLR-01 | フィルタ解除   | `clearFilters` を呼び出し     | 全てのフィルタ選択が null に戻ること                            |

## 4. ナビゲーションテスト (Event)
**目的:** UI 操作に伴う副作用（ViewEvent）が正しく発行されることを検証する。

| ID     | テスト項目 | 操作                   | 期待結果                                      |
|:-------|:------|:---------------------|:------------------------------------------|
| NAV-01 | 戻る操作  | `navigateBack` を呼び出し | `AuditLogViewEvent.NavigateBack` が発行されること |
