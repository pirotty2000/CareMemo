# テスト仕様書 - AlertReportViewModel

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/viewmodel/AlertReportViewModelTest.kt` (予定)

## 1. 概要
アラート・レポート画面の ViewModel における状態遷移、データ取得フロー、およびイベント処理を検証する。
`AlertReportLogic` との連携や、UI 状態（Loading/Active/Error）の管理を対象とする。

## 2. 初期化・ロードテスト
**目的:** 画面起動時のデータ取得と状態遷移が正しく行われることを検証する。

| ID     | テスト項目      | 条件                       | 期待結果                                      |
|:-------|:-----------|:-------------------------|:------------------------------------------|
| INI-01 | 初期ロード成功    | 正常にデータがスキャンされる           | `screenState` が Active になり、アラート一覧が保持されること |
| INI-02 | 初期ロード失敗    | スキャン処理で例外が発生する           | `screenState` が Error になること               |
| INI-03 | 利用者絞り込みロード | `personId` が渡された状態で起動される | その利用者のアラートのみにフィルタリングされていること               |

## 3. 操作・イベントテスト
**目的:** ユーザー操作に応じた状態更新や遷移イベントの発火を検証する。

| ID     | テスト項目      | 条件                    | 期待結果                                  |
|:-------|:-----------|:----------------------|:--------------------------------------|
| OPR-01 | カテゴリフィルタ変更 | フィルタ種別（バイタル等）を変更する    | `filteredAlerts` が指定カテゴリのもののみになること    |
| OPR-02 | 手動リフレッシュ   | リフレッシュ操作を行う           | 再度スキャンが実行され、最新の状態に更新されること             |
| NAV-01 | 詳細画面への遷移   | アラート項目を選択する           | `NavigateToDetail` イベントが正しい引数で発行されること |
| MSK-01 | マスク設定の反映   | 設定画面でマスクのON/OFFが切り替わる | 表示されている氏名のマスク状態が即座に更新されること            |
| AUD-01 | 監査ログの記録    | スキャンが実行される            | 「AlertReport」機能のスキャン開始ログが記録されること      |
