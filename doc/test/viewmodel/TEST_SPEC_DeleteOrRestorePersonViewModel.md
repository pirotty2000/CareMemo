# テスト仕様書 - DeleteOrRestorePersonViewModel

- **対象テストコード:**
    - `app/src/test/java/jp/mydns/fujiwara/carememo/viewmodel/DeleteOrRestorePersonViewModelTest.kt`

## 1. 概要
利用者の復帰・抹消画面（SCR-S-003）における、対象者の選択管理、一括処理（復帰・完全抹消）の実行、モード切り替えに伴う UI 状態の管理、および画面遷移イベントの正確性を検証する。

## 2. 初期化・データロードテスト (Initialization)
**目的:** 画面起動時に正しく引数（モード）が処理され、アーカイブ済み利用者のリストが自動ロードされることを検証する。

| ID     | テスト項目    | 検証内容                                       | 期待結果                                          |
|:-------|:---------|:-------------------------------------------|:----------------------------------------------|
| INI-01 | 自動ロード成功  | `DeleteOrRestorePersonViewModel` のインスタンス化  | 削除済み利用者リストの購読が開始され、`archivedPersons` に反映されること |
| INI-02 | モード指定の反映 | `SavedStateHandle` で `"DELETE"` モードを指定して起動 | `uiState.mode` が `DELETE` で初期化されること           |
| INI-03 | 伏せ字設定反映  | `isNameMaskingEnabled` 設定の変更               | UI 状態の `isNameMaskingEnabled` に即座に反映されること     |

## 3. 選択状態管理テスト (Selection)
**目的:** 利用者の選択・解除操作、および全選択・一括解除が正しく状態に反映されることを検証する。

| ID     | テスト項目      | 条件 (操作)                   | 期待結果 (UiState)                                    |
|:-------|:-----------|:--------------------------|:--------------------------------------------------|
| SEL-01 | 個別選択の反転    | `toggleSelection(id)` を実行 | `selectedIds` に対象が含まれる/含まれない状態が正しく切り替わること         |
| SEL-02 | モード変更時のクリア | `setMode` でモードを切り替え       | `mode` が更新され、以前の選択状態 (`selectedIds`) が空にリセットされること |
| SEL-03 | 全選択        | `selectAll(list)` を実行     | リストに含まれる全利用者の ID が `selectedIds` に追加されること         |
| SEL-04 | 選択クリア      | `clearSelection()` を実行    | `selectedIds` が空になること                             |

## 4. 処理実行テスト (Execution)
**目的:** 復帰・抹消処理の実行ロジック、バリデーション、およびエラー発生時の安全性を検証する。

| ID     | テスト項目     | 条件                                | 期待結果                                                               |
|:-------|:----------|:----------------------------------|:-------------------------------------------------------------------|
| EXE-01 | 復帰処理成功    | 1名選択して `restoreSelectedPersons()` | リポジトリの `restorePersonsBatch` が呼ばれ、選択が解除されること                       |
| EXE-02 | 抹消処理成功    | 1名選択して `deleteSelectedPersons()`  | リポジトリの `permanentlyDeletePersonsBatch` が呼ばれ、選択が解除されること             |
| EXE-03 | 未選択エラー    | 選択なしの状態で保存ボタン（復帰/抹消）を実行           | 処理が中断され、バリデーションエラーダイアログ（R.string.archive_err_no_selection）が表示されること |
| EXE-04 | 実行失敗時の安全性 | リポジトリで例外が発生                       | `isLoading` が解除され、監査ログに `ERROR` が記録されること                           |

|:-------|:------|:-----------------------|:---------------------------------------|
| NAV-01 | 戻る操作  | `navigateBack()` を呼び出し | `viewEvent` から `NavigateBack` が発行されること |
