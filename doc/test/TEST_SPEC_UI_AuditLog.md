# UI層テスト仕様書 - AuditLog (操作ログ)

- **対象テストコード:**
    - `androidTest/java/jp/mydns/fujiwara/carememo/ui/screens/settings/AuditLogScreenTest.kt`
    - `test/java/jp/mydns/fujiwara/carememo/data/repository/AuditLogRepositoryTest.kt`

## 1. 画面表示テスト (AuditLogScreen)
**目的:** 操作ログ画面の各要素が正しく表示され、データの有無に応じた表示切り替えが機能することを検証する。

| ID    | テスト項目      | 検証内容                                            |
|:------|:-----------|:------------------------------------------------|
| CP-01 | 基本レイアウト表示  | タイトル「操作ログ」と戻るボタンが表示されていること。                     |
| CP-02 | ログなし状態の表示  | 記録が1件もない時、専用の空状態（EmptyState）メッセージが表示されること。      |
| CP-03 | ログリスト表示    | ログが存在する場合、カード形式のリスト（AuditLogItem）で正しく表示されていること。 |
| CP-04 | フィルターバーの表示 | テーブル絞り込みおよび画面絞り込みのチップ（FilterChip）が表示されていること。    |
| CP-05 | 検索結果なし表示   | フィルター条件に一致するログがない時、「条件に合うログはありません」と表示されること。     |

## 2. 画面全体の挙動・結合テスト (AuditLogScreen)
**目的:** 絞り込み操作やナビゲーションが正しくViewModelと連動することを検証する。

| ID    | テスト項目      | 検証内容                                                           |
|:------|:-----------|:---------------------------------------------------------------|
| BH-01 | テーブル絞り込み操作 | テーブルフィルターをタップしてドロップダウンを開き、項目を選択した際に ViewModel のフィルター処理が呼ばれること。 |
| BH-02 | 画面絞り込み操作   | 画面フィルターをタップしてドロップダウンを開き、項目を選択した際に ViewModel のフィルター処理が呼ばれること。   |
| BH-03 | フィルター解除    | 解除ボタン（×）をタップした際、全ての絞り込み条件がクリアされること。                            |
| BH-04 | 戻る操作       | 戻るボタンをタップした際、`onBack` コールバックが呼ばれること。                           |
| BH-05 | アクション別の色分け | アクションの種類（INSERT, UPDATE, DELETE等）に応じて、文字色が定義通りに設定されていること。      |

## 3. ロジック・安全性テスト (AuditLogRepository)
**目的:** ログ記録の失敗がアプリ全体の動作に影響を及ぼさないことを検証する。

 ID    | テスト項目      | 検証内容                                                           |
:------|:-----------|:---------------------------------------------------------------|
 LG-01 | 例外保護       | ログ記録時に例外（DBエラー等）が発生しても、呼び出し元に例外を投げず正常終了すること。 |
 LG-02 | 非同期安全性     | `NonCancellable` により、コルーチンがキャンセルされてもログの書き込みが試行されること。 |

## 4. テスト用タグ (testTag) 定義
- `AuditLog_BackButton`: 戻るボタン
- `AuditLog_TableFilter`: テーブル絞り込みチップ
- `AuditLog_ScreenFilter`: 画面絞り込みチップ
- `AuditLog_FilterClear`: フィルター解除ボタン
- `AuditLog_EmptyState`: 空状態表示
- `AuditLog_List`: ログ一覧（LazyColumn）
- `AuditLogItem_{id}`: 各ログ項目
