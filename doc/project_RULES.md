# CareMemo 開発ルール (基本憲法)

本ドキュメントは、CareMemo プロジェクトにおける設計思想と最優先の行動規範を定義します。具体的な実装手順や詳細な制約については、各専門ドキュメントを参照してください。

## 1. 開発の基本指針

- **既存コードとの一貫性の優先 [最優先]**
  - 本プロジェクトでは「一般的なベストプラクティス」よりも、**既存コードとの一貫性を最優先**します。
  - すでに同様の実装が存在する場合は、既存の設計・命名規則・責務分割を忠実に踏襲してください。
- **影響範囲の最小化**
  - 依頼された修正内容以外について、不用意な設計変更やファイル整理を行わないでください。
- **不要なリファクタリングの禁止**
  - 「将来のため」「命名変更のみ」といった理由での修正は行わず、改善が必要な場合はまず「提案」を行ってください。
