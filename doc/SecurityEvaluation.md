# 『CareMemo』個人情報保護およびセキュリティ実装評価報告書（2026年8月版・完全版）

## 1. エグゼクティブサマリー
本アプリケーションのセキュリティ実装状況を再検証しました。「インターネット権限を持たない完全オフライン設計」に加え、ユーザーが意識せずとも保護が機能する「セーフティ・バイ・デフォルト」の考え方が徹底されています。

一方で、現場での利便性（UX）を追求した結果、パスワードの強度やデータの外部共有において、システム的な制限ではなく「利用者のモラルと運用」に依存する「既知の弱点」が意図的に残されています。これらは利便性と堅牢性のトレードオフであり、導入組織には適切な教育と運用ルールの整備が求められます。

**判定：業務利用を承認（ただし、運用ルールの厳格化を必須条件とする）**

## 2. 評価済みの主要なセキュリティ実装（強み）

### 2.1 強固なデータ保護基盤
*   **データベース暗号化 (SQLCipher)**: `AES-256` による Room DB 全体の透過的暗号化。
*   **物理アクセス制限**: 生体認証によるアプリロックおよびタイムアウト後の自動ロック。
*   **画面保護**: `FLAG_SECURE` 実装による OS レベルの録画・履歴画面の秘匿。

### 2.2 メディアプライバシーの徹底保護
*   **内部ストレージへの隔離保存**: 写真データは Android システムのギャラリーアプリや他のアプリから一切参照できない「アプリ専用領域（Internal Storage）」に保存。他アプリによる不正な覗き見や意図しないクラウド同期を構造的に防止。
*   **Exif情報の自動完全削除**: 画像保存時に、撮影場所（GPS）や端末情報を含むメタデータ（Exif）を自動的に削除。写真データそのものからのプライバシー流出を完全に遮断。

### 2.3 セーフティ・バイ・デフォルト（構造的なガードレール）
*   **初期設定の強制**: 「伏せ字表示」「バックアップパスワード」等は**初期状態で「有効（ON）」**となっており、設定漏れを防ぐ設計。
*   **PDF出力の強制保護**: 設定の有無にかかわらず、PDF出力時はシステムレベルで**常に「氏名の伏せ字処理」を強制適用**。
*   **重要操作の再認証**: セキュリティ設定の変更やパスワードの平文表示を行う際、必ず生体認証を要求する多層防御。

### 2.4 証跡管理
*   **監査ログ (AuditLog)**: すべての重要操作（CRUD、出力、設定変更）を記録。不審な操作の事後追跡を可能に。

## 3. 識別された「既知の弱点」とリスク評価（利便性とのトレードオフ）

本アプリには、現場の利便性を最優先した結果として生じている、以下のセキュリティ上の弱点が存在します。

### 3.1 パスワード強度と「人間の脆弱性」
*   **仕様**: バックアップパスワード等は、現場での入力負荷を考慮し、**「数字のみ・最小6文字」**からの設定を許容している。
*   **リスク**: システム的な複雑性（英数字混合等）を強制していないため、「000000」や「123456」といった安易なパスワードが設定されるリスクが極めて高い。この場合、暗号化の堅牢性は意味をなさなくなります。

### 3.2 共有機能（Intent）による「情報の出口」の不確実性
*   **仕様**: PDF出力機能は、Android 標準の共有機能（Intent）を利用し、あらゆるアプリにデータを渡せる状態にある。
*   **リスク**: PDF自体にパスワードとマスキングが施されているとはいえ、共有先（私用メール、未認可クラウド等）の選定は完全に「人間（利用者）」の判断に委ねられている。

## 4. 業務利用における遵守条件（セキュリティポリシー）
本アプリの弱点を補完するため、導入組織は以下のルールを徹底すること。

1.  **パスワードの品質管理**: バックアップパスワードには、推測されやすい連続数字や生年月日を避け、可能な限りランダムな数字を設定するよう指導すること。
2.  **認可アプリへの共有限定**: PDFおよびZIPの共有先は、組織が認可した業務用アプリ（法人用Teams, Slack等）に限定すること。
3.  **OSセキュリティの維持**: 最新のセキュリティアップデートを適用し、生体認証機能を有効に保つこと。

---

## 5. 最終結論
本アプリは、Android プラットフォーム上で構築可能な業務アプリとして、最高水準の「防御機能」を備えています。しかし、最後にその鍵をかけるのは「人間」であり、利便性を優先した箇所がそのままリスクの入り口となり得ます。

導入にあたっては、この「既知の弱点」を組織全体で共有し、適切な教育を行うことを前提として、現場での業務利用を承認します。
